V3 有潜力成为本轮核心贡献：相对 tracker ensemble/MHT/DAM4SAM，真正新意在“异构记忆后验融合 + 用融合后验反向门控多个自更新记忆”，且直指确认偏差。但目前逻辑与预注册还不足以支撑 T-RO/RA-L/CCF-A 级主贡献。

**MAJOR**

1. **H3c 机理检验有闭环污染。**  
   在 V3 日志中测 TAHRelM 与 DAM4SAM 错误相关性，已经被融合后验和互相门控改变；ρ_err 不能证明“原始误差低相关导致融合增益”。  
   建议：在同种子先记录无互门控 observe/基线下两源选择，报告 pre-gating ρ_err、条件概率 `P(DAM错|TAH错)`、错锁持续时间重叠；V3 内ρ只作附录。

2. **缺少关键对照，无法排除普通集成或重置收益。**  
   当前消融只有 noDAMgate、nolang，不足以证明核心是“融合后验门控各记忆”。  
   建议预注册：fusion-commit-only、fusion-noTAHgate、fusion-noDAMgate、TAH+DAM 单帧加权/投票不回灌、DAM-only PGIF、TAH-only PGIF、固定/低置信 re-init 对照。至少要证明 V3 优于“普通异构 ensemble + 不门控记忆”。

3. **α 与置信秩融合仍偏启发式。**  
   `α_lang=0.5` 基于单帧准确率约 0.42，但语言错误可能与 TAH 冷启动高度同源；TAH/DAM 权重同为1也未论证。rank 权重只解决尺度，不解决源可靠性与错误相关性。  
   建议：冻结一套非评测种子/离线日志确定 α；或预注册 α 敏感性和等权主结果。报告各源 AUROC、ECE/可靠性、缺席率。

4. **融合后验可能制造“群体确认偏差”。**  
   若融合早期错，V3 会同时改写 TAHRelM、重置 SAM2，并让两路后续观测趋同，反而降低独立性。  
   建议：记录门控前后两源分歧率、错误相关时间、错误门控次数；加入“只门控一个记忆”的对照。

5. **V2 条件继承有选择偏差风险。**  
   “若 V2 通过门控则继承”虽预先写明，但若 V2 与 V3用同一 Town05 seeds 91000–19，相当于在评测集上选择组件。  
   建议：V3 主表同时报告 with/without V2；或用独立验证种子决定分支。

**MINOR**

- H3a 可证伪且方向合理，但应同时报告最长连续正确锁定，避免只在两个指标上取 Pareto。  
- H3c 阈值 0.5/0.7 偏任意，建议定义为解释性而非通过门槛。  
- DAM4SAM 160px 匹配门限、冷却3步需报告敏感性、缺席比例、重置次数与耗时。  
- “MHT差异”表述需收窄：V3仍是单假设后验累积，不应暗示解决完整多目标身份管理。

结论：方向有一区潜力，但现在应判 **MAJOR**；补齐闭环污染的机理证据与 ensemble/门控拆分对照后，创新链条会强很多。
