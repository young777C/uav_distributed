# ACoT-VLA 深度解读：动作思维链

> **论文**：Zhong et al., Beihang University & AgiBot (智元), Jan 2026
> **arXiv**：[2601.11404](https://arxiv.org/abs/2601.11404)
> **代码**：[github.com/AgibotTech/ACoT-VLA](https://github.com/AgibotTech/ACoT-VLA)
> **核心贡献**：**将 CoT 从文本空间搬到动作空间**——不去写"我应该先抓再放"的文字推理，而是直接生成粗粒度的参考动作轨迹作为"思维链"来引导最终动作。

---

## 1. 核心洞察：文本 CoT 在 VLA 中的根本局限

### 现有的两种"VLA 推理"

```
类型 1：语言 CoT（RT-2 + CoT, CognitiveDrone-R1）
  图像 → VLM → "我应该先靠近目标，然后抓取，最后放到碗里" → 动作
  问题：从文字"靠近目标"到实际行动 vx=0.5,vy=-0.3 之间存在巨大的 gap
       文字是离散、抽象的，动作是连续、精确的
       → 语义-运动学鸿沟（Semantic-Kinematic Gap）

类型 2：目标图像合成
  图像 → VLM → 合成"抓取成功后的图像" → 基于合成图像生成动作
  问题：合成图像本身有误差，且图像→动作仍需要额外步骤
```

### ACoT 的关键洞察

> **为什么不在动作空间里推理？** 如果 VLA 需要生成精细的动作，那"中间推理"也应该是动作——粗粒度的参考轨迹——而不是文字或图像。

```
传统 CoT（语言空间）：                     ACoT（动作空间）：
  "先观察物体位置"                           动作 token₁: 靠近物体
  "判断抓取角度"          →                 动作 token₂: 调整手爪姿态
  "手指靠近并抓取"                           动作 token₃: 闭合手指
  "提起并移动到目标位置"                       动作 token₄: 抬起并平移

  文字推理                                     动作轨迹推理
  跨模态鸿沟                                   同模态，直接可执行
```

## 2. 架构：双推理器 + 融合头

```
输入：RGB 图像 + 语言指令
  │
  ▼
┌─────────────────────────────┐
│      VLM 骨干（冻结/微调）    │
│  输出：KV Cache（多模态上下文） │
└──────────┬──────────────────┘
           │
     ┌─────┴─────┐
     ▼           ▼
┌─────────┐ ┌─────────┐
│  EAR    │ │  IAR    │
│ 显式动作 │ │ 隐式动作  │
│ 推理器   │ │ 推理器   │
└────┬────┘ └────┬────┘
     │           │
     ▼           ▼
   Zᵉˣ         Zⁱᵐ
  (粗粒度参考  (隐式动作先验:
   轨迹序列)    可供性、抓取线索、
               力控先验)
     │           │
     └─────┬─────┘
           ▼
   ┌───────────────┐
   │  AGP 融合头    │
   │ 双交叉注意力    │
   └───────┬───────┘
           ▼
      最终动作序列
```

### 2.1 Explicit Action Reasoner (EAR) — 显式动作推理

```
输入：噪声动作序列（随机初始化）+ VLM KV Cache
  ↓
轻量 Transformer：
  Self-Attention：捕捉动作序列内部的时序依赖
  Cross-Attention：注入 VLM 的多模态上下文
  ↓
输出：去噪后的粗粒度参考轨迹 → MLP 投影 → Zᵉˣ

训练方式：Flow Matching（与 π₀ 一致）
```

**这其实就是把扩散/流匹配的"噪声→动作"过程，显式地用 VLM 上下文来引导。** 不同的是，EAR 输出的不是最终动作，而是"参考轨迹"——一个告诉最终动作头"大概应该这样做"的粗粒度引导信号。

### 2.2 Implicit Action Reasoner (IAR) — 隐式动作推理

```
输入：VLM 各层的 KV Cache
  ↓
对每一层：
  初始化可学习的 query 矩阵
  下采样 K/V 到低维空间
  Cross-Attention：query attend 下采样后的 K/V → 提取动作相关特征
  ↓
所有层的输出 → Average Pooling → MLP 投影 → Zⁱᵐ
```

**IAR 从 VLM 的内部表征中提取"说不出来但很有用"的动作先验。** 比如：
- 这个物体看起来是软的还是硬的？（决定抓取力度）——可供性（affordance）
- 这个杯子应该从上方还是侧面抓？——抓取线索（grasping cues）
- 碗里有没有液体？（影响移动速度）——力控先验（force priors）

这些信息在 VLM 的中间层已经编码了，但用自然语言表达不出来。IAR 绕过了语言，直接从 VLM 的隐藏状态中提取。

### 2.3 Action-Guided Prediction (AGP) 头

```
Zᵉˣ (粗粒度参考轨迹)    Zⁱᵐ (隐式动作先验)
        │                      │
        └──────────┬───────────┘
                   ▼
        Dual Cross-Attention：
          动作 query ←→ Zᵉˣ
          动作 query ←→ Zⁱᵐ
                   │
                   ▼
        Concat + Self-Attention → 统一的动作表征
                   │
                   ▼
              Flow Matching → 最终动作序列
```

## 3. 关键实验结果

### LIBERO（最核心的 benchmark）

| 方法 | Spatial | Object | Goal | Long | **Avg.** |
|---|---|---|---|---|---|
| Diffusion Policy | 78.3 | 92.5 | 68.3 | 50.5 | 72.4 |
| π₀ | 96.8 | 98.8 | 95.8 | 85.2 | 94.1 |
| π₀.₅ | 98.8 | 98.2 | 98.0 | 92.4 | 96.9 |
| OpenVLA-OFT | 97.6 | 98.4 | 97.9 | 94.5 | 97.1 |
| **ACoT-VLA** | **99.4** | **99.6** | **98.8** | **96.0** | **98.5** |

### 核心分析

> **在 Long 任务上增益最大（96.0% vs 94.5%）——** 因为长任务最需要"分步推理"。短任务（Spatial 99.4%）中显式和隐式推理的帮助相对较小——短任务不太需要思考。

### LIBERO-Plus（泛化测试）

| 条件 | ACoT-VLA | 次优方法 |
|---|---|---|
| 标准 | **84.1%** | 75.7% |
| 相机视角扰动 | **+11.6%** over baseline | — |
| 未见纹理 | **+12.2%** IS on VLABench | — |
| 机器人初始状态扰动（零样本） | **88.0%** (+16.3%) | — |

### 真机实验

| 平台 | 任务 | 成功率 |
|---|---|---|
| AgiBot G1 + AgileX | 擦拭、倒水、开放抓取 | ACoT-VLA **66.7%** vs π₀.₅ 61.0% vs π₀ 33.8% |

### 关键消融

| 配置 | LIBERO Avg. |
|---|---|
| 完整 ACoT-VLA (EAR + IAR) | **98.5%** |
| 仅 EAR | ~97.5% |
| 仅 IAR | ~97.0% |
| 无推理（baseline） | ~96.0% |

**结论**：EAR 和 IAR 各自独立贡献 ~1-1.5pp，组合后接近 2.5pp 的提升——两者互补。

### 冻结 LLM 骨干的结果

```
ACoT-VLA (全量微调): 98.5%
ACoT-VLA (冻结 LLM): 98.5%
```

**惊人的发现**：冻结 LLM 骨干对性能完全没有影响！这说明 EAR + IAR 的推理能力主要来自"怎么利用 VLM 已有的表征"，而不是"让 VLM 学新东西"。这对部署极其有利——冻结骨干意味着显存和训练成本大幅降低。

## 4. 和已有工作的定位

### 4.1 vs 语言 CoT（RT-2 + CoT, CognitiveDrone-R1）

| | 语言 CoT | ACoT |
|---|---|---|
| **推理空间** | 自然语言 token | **动作空间** |
| **中间表征** | 文字（离散、抽象） | 轨迹序列（连续、可直接执行） |
| **语义-运动 gap** | 存在（"靠近" → vx=0.5 需要额外解码） | **不存在**（推理和动作在同一空间） |
| **推理成本** | 高（自回归生成文本） | 中（Flow Matching 去噪） |

### 4.2 vs 本文讨论过的其他 VLA 工作

| 工作 | 推理方式 | 与 ACoT 的关系 |
|---|---|---|
| **π₀ / π₀.₅** | 无显式推理，端到端 flow matching | ACoT 以此为基础，加了动作空间的推理 |
| **OpenVLA** | 无推理，自回归动作 token | ACoT 展示了"推理"的增益 |
| **Z-1** | GRPO 后训练优化 | 互补——可以用 Z-1 的方式后训练 ACoT |
| **VLA-AN** | 语言推理（Stage I SFT） | ACoT 在动作空间做类似的事，更快更直接 |
| **TrackVLA** | 锚点扩散 | EAR 的流匹配 + KV 条件化和 TrackVLA 有相似之处 |

### 4.3 vs 同期工作

| 方法 | 时间 | 推理方式 |
|---|---|---|
| **ACoT-VLA** | 2026.01 | 显式动作轨迹 + 隐式 VLM 先验 |
| **LaRA-VLA** | 2026.02 | 隐式 latent 推理（消除显式 CoT 开销） |
| **HyT** | 2025.10 | 训练时用 CoT，推理时可跳过 |

## 5. 对 UAV-VLA 的直接启示

### 5.1 "动作思维链"比"语言思维链"更适合无人机控制

```
UAV 的语言 CoT（CognitiveDrone 风格）：
  "先识别目标电线杆 → 判断当前通信质量 → 决定巡检路线"

问题：
  "决定巡检路线" → 实际 3D 轨迹点需要另一个模块来生成
  语言→动作的跨模态 gap 在无人机 6-DoF 空间中更严重

UAV 的动作 CoT：
  EAR 直接生成粗粒度 3D 轨迹：
    waypoint₁: 飞到塔正面
    waypoint₂: 调整相机朝向
    waypoint₃: 拍摄
    waypoint₄: 飞往下一目标
  
  然后 AGP 头根据这个粗轨迹生成精细的飞行动作
```

### 5.2 隐式推理器（IAR）在 UAV 中的独特价值

IAR 从 VLM 内部提取的"说不出来"的线索，在 UAV 场景中可能包括：

- **隐含的风场信息**：树叶摆动 → VLM 内部编码了"有风"→ IAR 提取这个先验 → 动作更稳
- **障碍物的物理属性**："铁丝网" vs "砖墙"的穿越风险不同 → VLM 知道但不会说出来 → IAR 提取
- **通信质量的视觉暗示**：远处有高楼 → 可能遮挡信号 → IAR 提取这个"潜规则"

这些是语言 CoT 永远覆盖不到的信息。

### 5.3 冻结骨干的意义

ACoT-VLA 证明**冻结 VLM 骨干也能达到 98.5%**。这对 UAV 极其重要：

```
机载部署可以：
  VLM 骨干：预训练好的，冻结 → 不占反向传播的显存
  EAR + IAR + AGP：轻量模块，只占少量显存
  → 可以用大 VLM 的视觉理解能力，但不承担其训练/推理的全部开销
```

## 6. 局限

1. **依赖 Flow Matching 架构**——不直接适用于离散 token VLA（如 OpenVLA）
2. **EAR 生成的参考轨迹粒度**如何确定——过粗 = 没有引导作用，过细 = 和最终动作没有区别
3. **真机实验有限**——仅 66.7% 成功率，sim-to-real gap 仍需解决
4. **IAR 的可解释性**——它提取了什么 "隐式先验"？目前是黑盒
5. **UAV 验证缺失**——当前仅在桌面操作任务上验证

---

## 7. 一句话总结

> ACoT-VLA 第一个证明了 **"在动作空间里推理"比"用语言描述动作"更有效**——显式动作推理器（EAR）生成粗粒度参考轨迹，隐式动作推理器（IAR）从 VLM 内部提取说不出来的动作先验，两者配合将 LIBERO 推到 98.5% SOTA。对 UAV 的核心启示：**不要用语言描述飞行轨迹，直接让模型在动作空间里"想"轨迹。**
