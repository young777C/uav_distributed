4 个可训练模块 · 前向

在冻结 VLM 特征之上
共享一个优化器

EAR · 显式动作推理d256·4L·4H

预测目标未来在哪(K=4 航点)。flow-matching 学向量场。

in ← vlm_ctx + proprio  ·  out → z_ex(航点引导)

→ waypoints → l_ear

IAR · 隐式动作推理d256·n_im8·4H

逐 VLM 层 query → 8 个隐式 token z_im;附带 2 个辅助头。

in ← vlm_ctx_layers(5层)  ·  out → z_im + aux

occ_head → l_vismaneuver_head → l_man

DiT · 动作头(真正的输出)d512·32L·8H

flow-matching 去噪 16 步动作块;三重 cross-attention(EAR几何 / IAR语义 / VLM上下文,不同频率)。

in ← 噪声动作 a_t + t + z_ex + z_im + vlm_ctx + proprio

→ v_hat → l_act(visible 掩码)
★ staleness 增强:推理时慢系统 S2 引导是"过期"的 → 训练时故意给 z_ex 加降质噪声,让模型对异步鲁棒。

TargetIDHead(tid)· 语言消歧d256·4H·drop0.1

每辆候选作为 query,cross-attend 100 个 VLM 上下文 token → "语言在说我吗?" → 打分。

in ← cand_feats(query) × vlm_ctx(含语言)

→ logits (N) → l_tid(CE,tid_valid掩码)
★ 唯一 load-bearing 语言信号。用 cross-attn 而非均值池化 → 每车独立"查"语言,不被稀释。mis_follow 测的就是这个头。

多任务损失聚合

5 个任务头 → 1 个标量
L = L_act + 0.3·L_ear + 0.1·L_vis + 0.1·L_man + 0.5·L_tid
★ 为什么这么多头:密集分解监督 = 强迫共享表征编码"目标去哪/是否遮挡/哪辆是目标"等可验证子技能,而非蒙一个捷径;每个中间量都能单独评测(正是这样才查出了位置捷径、指标漏洞)。

优化 & 训练控制

50 epoch · 稳定化四件套

AdamW · 双参数组

tid 头 wd=1e-2(强正则),其余 wd=1e-4。
+ 余弦 LR 衰减 + grad_clip 1.0。

★ 稳住薄语言信号:tid 头在 66 集上过拟合快(val 早峰晚衰)→ dropout + 独立高 wd + 余弦 LR 把有语言臂从"漂回 chance"钉成稳定收敛(gap 3pp→15pp)。
