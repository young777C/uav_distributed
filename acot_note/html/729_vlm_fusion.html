语言如何融入视觉 · 训练/推理流程

给非 VLM 背景:从 token 讲起 → 注意力融合 → 冻结缓存 → 训练与部署

语言 token 图像 token(100) 融合后·被语言点亮 动作输出

先补 4 个 VLM 基础概念

① Token(令牌)

把输入切成小块再各自变成一个向量。文字切成子词(the / yellow / Jeep…);图像切成小块 patch(本项目 100 块 = 10×10)。

② Embedding(向量)

每个 token 变成一个 2560 维向量 —— 它在"语义空间"里的坐标。相近含义→相近坐标。

③ Self-Attention(自注意力)

核心机制:每个 token 环顾其它 token,决定"听谁多一点"(注意力权重),再把它们的信息按权重汇入自己。逐层堆叠→不断吸收上下文。

④ Causal Mask(因果遮罩)

每个 token 只能看它左边(前面)的 token。所以顺序很重要:本项目把文本放在图像前面,图像才能"看到"指令。

语言如何融入视觉:注意力让"匹配指令的图块被点亮"

一条序列 = [文本 token] + [图像 token×100]。逐层自注意力中,每个图像 token 向前 attend 到文本词;与描述匹配的图块把"yellow/Jeep"的语义汇入自己。

读法:目标车所在的图块(紫)对 yellow / Jeep 产生强注意力(粗线),把语言语义吸进自己的 2560 维向量;背景图块对语言注意力弱(细线),保持"暗"。 堆叠多层后,输出的 (100, 2560) 已是语言染色的视觉特征 —— 换指令(如"track the red car")会点亮不同图块。这就是"不是纯图像特征"的含义。

延伸:connector ≠ 融合 —— 视觉如何接入 LLM(分层)

上面的"融合"发生在 LLM 内部的自注意力。它前面还有一站叫 connector:把 ViT 视觉特征"搬进" LLM(对齐维度 / 压缩 token),本身不做语义融合。你说的 5 种,前 3 种是 connector 的互斥架构,后 2 种是正交的 token 管理。

Connector:3 种互斥架构

·
MLP 投影 ★ 线性投到 LLM 维,图像 token 拼进序列,融合甩给 LLM 自注意力(本项目/LLaVA/Qwen)
·
交叉注意力 LLM 里插专门 cross-attn 层做文本→图像(Flamingo)——connector 里就融合了
·
Q-Former 可学习 query 蒸馏出固定少量 token(BLIP-2)——进 LLM 前的部分融合

正交的 token 管理(可叠加)

·
空间重排 ★ 2×2 patch 折叠 → 减 token(→~10×10)。本项目 spatial_merge=2
·
动态分辨率 ★ token 数随图尺寸变(min/max_pixels 控制)
★ = 本项目:动态分辨率 + 空间merge2×2 + MLP投影 → LLM自注意力融合

关键:connector 决定"融合在哪发生"。MLP 投影(本项目)= connector 只对齐、融合留给 LLM,所以两者是清楚的两站;而交叉注意力 / Q-Former 把两步合并。这就是"它俩不是一回事"的准确含义。

训练 vs 推理:同一套模型,两种用法

训练(离线,有标签)

1
预计算一次:每(帧+指令)过冻结 Qwen → 存 (5,100,2560) 缓存。VLM 之后不再前向。
2
每步从缓存取一批,喂给小模型 IAR/EAR/DiT/target_id。
3
EAR/DiT 用 flow-matching:学一个"噪声→轨迹/动作"的向量场(预测该往哪推)。
4
与真实标签算 loss(动作MSE+ear+vis+man+tid)→ 反传只更新小模型(VLM 冻结)。
5
重复 50 epoch,课程 a→c。
产物:stage2_best.pt · 指标 mis_follow ~3%

推理(在线,无标签,闭环)

1
实时相机帧 + 指令 → 慢系统 S2(~1Hz)跑 Qwen → 得到当前 ctx。
2
快系统 S1(~20Hz):EAR/IAR/DiT 用最新 ctx,采样生成 16 步动作块。
3
flow-matching 反过来用:从随机噪声出发,沿学到的向量场积分 ODE → 采样出动作。
4
target_id 用指令选哪辆车 → 执行动作第一步 → 重新观测。
5
滚动重规划:每步用新帧闭环,趋势靠高频纠正累积。
无 loss、无反传;VLM 在线跑(而非缓存)。

一句话对照:训练 = VLM 预计算成缓存 + 算 loss + 反传(更新小模型);推理 = VLM 实时跑 + 采样生成动作 + 闭环执行。flow-matching 在训练时学"向量场"、推理时"沿向量场积分采样"——同一个网络,一个算损失、一个做生成。
