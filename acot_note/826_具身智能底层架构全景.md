> 基于 2024-2025 年最新综述与论文整理

## 一、架构总体分类

具身智能的底层架构可以从**决策范式**和**建模目标**两个维度进行分类。

### 1.1 按决策范式分

```text
具身智能底层架构
├── 模块化架构 (Modular)
│   └── 感知 → 规划 → 控制 分离，独立优化
│
├── 端到端架构 (End-to-End)
│   ├── 模仿学习 (IL/BC)
│   ├── 强化学习 (RL)
│   ├── VLA (Vision-Language-Action)
│   └── Diffusion Policy
│
├── 混合架构 (Hybrid)
│   ├── LLM 高层规划 + 低层控制器
│   └── 显式推理层 + 端到端执行
│
└── 预测式架构 (Predictive)
```

### 1.2 四大范式的建模目标对比

| 范式 | 建模目标 | 核心能力 | 代表工作 |
|------|---------|---------|---------|
| **VLA** | P(a \| o, l) | 观测→动作的响应式映射 | RT-2, OpenVLA, π₀, TrackVLA |
| **World Model** | P(o' \| o, a) | 预测动作的未来后果 | DreamerV3, Sora, V-JEPA, TD-MPC2 |
| **WAM** | P(o', a \| o, l) | 联合预测未来状态 + 生成动作 | GR-1/2, DreamZero, CoVAR, DUST |
| **RL Policy** | π(a \| s) | 通过试错最大化累积奖励 | PPO, SAC, QT-opt |

## 二、VLA (Vision-Language-Action) 架构详解

VLA 是 2024-2025 年最具影响力的具身架构范式，核心思路是将互联网规模预训练的视觉-语言知识迁移到机器人控制。

### 2.1 VLA 三大子类型

#### （1）模块化 VLA

```text
感知模块 → 决策模块 → 执行模块
   ↓           ↓           ↓
Vision     LLM规划    运动控制器
```

- **特点**：层层协作，功能解耦，标准化接口
- **优势**：可解释性强，模块独立优化
- **劣势**：无联合优化，误差跨模块累积
- **代表**：SayCan, PerAct, Code as Policies

#### （2）端到端 VLA

```text
Visual Input + Language → [Unified Model] → Action
```

| 子类 | 骨干 | 代表模型 |
|------|------|---------|
| Transformer-based | 统一 token 序列 | Gato, RT-Trajectory, Octo |
| Diffusion-based | 扩散去噪 | Diffusion Policy |
| LLM-based | 冻结/微调 LLM | Uni-NaVid, CEED-VLA |
| **VLM-based** | 预训练 VLM + Action Head | **RT-2, OpenVLA, π₀, TrackVLA** |

**端到端 VLA 通用架构**：

```text
┌──────────────┐    ┌──────────────┐    ┌──────────────┐
│ Vision        │───▶│ Cross-Modality│───▶│ LLM / VLM    │
│ Encoder       │    │ Projector     │    │ Backbone     │
│ (CLIP/DINO)   │    │ (MLP/Q-Former)│    │ (7B-55B)     │
└──────────────┘    └──────────────┘    └──────────────┘
                                                │
                                         ┌──────┴──────┐
                                         ▼              ▼
                                  ┌──────────┐   ┌──────────┐
                                  │ Language │   │ Action   │
                                  │ Head     │   │ Head     │
                                  └──────────┘   └──────────┘
```

#### （3）混合 VLA

在端到端架构中插入显式推理层，保持可解释性：

- **Prompt-guided**：HiRT, SmolVLA — 通过 prompt 注入任务知识
- **显式推理层**：EnerVerse, TrackVLA++ (Polar-CoT) — 中间推理 token

| 模型 | 机构 | 参数量 | 核心创新 |
|------|------|--------|---------|

## 三、World Model (世界模型) 架构

世界模型是**内部预测性模拟**，在行动前推理"如果我做 X，世界会变成什么样"。

### 3.1 核心思想

```text
传统策略:    观测 → 策略网络 → 动作
世界模型:    观测 → 世界模型 → 预测未来 → 规划 → 动作
                     ↑__________|
                   内部模拟循环
```

### 3.2 代表性 World Model

| 模型 | 机构 | 核心技术 |
|------|------|---------|
| DreamerV3 | DeepMind | 潜在状态空间 + RSSM + 世界模型 RL |
| TD-MPC2 | Nicklas Hansen | 无解码器的潜在世界模型 |
| DayDreamer | - | Dreamer 在真实机器人上的部署 |
| Sora | OpenAI | 视频生成作为世界模型 |
| V-JEPA | Meta (LeCun) | 联合嵌入预测架构，抽象特征预测 |
| NVIDIA Cosmos | NVIDIA | Predict1(预测) + Transfer1(迁移) + Reason1(推理) |
| UniSim | Google | 统一仿真世界模型 |
| Genie 2 | Google DeepMind | 交互式世界生成 |

## 四、WAM (World Action Model) — 新一代预测式架构

### 4.1 WAM 是什么？

**World Action Model (世界动作模型)** 是 2025 年兴起的新范式，将世界建模（预测未来状态）与动作生成统一到单一框架中。

```text
VLA:      观测 → 动作                  （响应式）
WM:       观测 + 候选动作 → 预测未来    （仅模拟）
WAM:      观测 → 预测未来 + 生成动作    （预测+执行统一）
```

**核心洞察**：让模型"想象动作的后果"再执行，而非简单地反应式输出。

### 4.2 WAM 架构分类

#### 分类轴 1：耦合策略

```text
WAM 架构
├── 级联式 WAM (Cascaded)
│   ├── 显式像素级: UniPi, VLP, AVDC, WoW
│   │   └── 生成完整 RGB 未来视频 → 逆动力学提取动作
│   └── 隐式潜在级: VPP, mimic-video, S-VAM
│       └── 跳过像素解码器，从中间特征直接生成动作
│
└── 联合式 WAM (Joint)  ← 2025 主流
    ├── 自回归联合: GR-1, GR-2, CoT-VLA, WorldVLA, VLA-JEPA
    │   └── 视频 token + 动作 token → 统一因果自回归
    └── 扩散联合: 
        ├── 统一流 (单 DiT): DreamZero, Cosmos Policy, PAD
        └── 多流 (多 DiT + Cross-Attn): CoVAR, DUST, DiT4DiT
```

#### 分类轴 2：推理路径（动作解码位置）

| 类型 | 机制 | 代表 |
|------|------|------|
| **Render-and-Decode** | 完整像素生成 → 提取动作 | UniPi, WoW |
| **Latent-Only** | 停在中间特征 → 直接输出动作 | VPP, S-VAM |
| **Video-Generation-Free** | 不用视频扩散，用 JEPA/语言 token 等 | DUST, VLA-JEPA, MoWM |

### 4.3 代表性 WAM 模型

| 模型 | 核心创新 |
|------|---------|
| **GR-1 / GR-2** | 自回归联合预测视频 + 动作 |
| **DreamZero** | 统一 DiT 流，联合去噪未来帧 + 动作 |
| **CoVAR** | 多流 WAM，视频 DiT 和动作 DiT 通过 Cross-Attention 耦合 |
| **DUST** | 多流 WAM，无需视频生成，紧凑表示 |
| **HiMem-WAM** | 层级记忆门控，动作感知潜在代码 |
| **Efficient-WAM** | 10 亿参数，30× 加速到 ~100ms 延迟 |
| **MoWM** | Mixture-of-World-Models，潜在模型 + 像素模型 |
| **WoW** | Flow-Mask 逆动力学闭环，VLM 自我纠错沙盒 |
| **Cosmos Policy** | NVIDIA 统一流 WAM |
| **DexWorldModel / CLWM** | DINOv3 潜在特征 + TTT Memory + 推测性异步推理 |

### 4.4 WAM 的数据生态

WAM 的独特优势在于能混合四种异构数据源：

| 数据源 | 示例 | 作用 |
|--------|------|------|
| 机器人遥操作 | OXE, DROID, RH20T | 精确控制微调 |
| 便携式人类演示 | FastUMI, RealOmni | 低成本交互动力学 |
| 仿真数据集 | ManiSkill, RoboCasa, RoboTwin | 无限动力学预训练 |
| **网络自我视频** | Ego4D, HowTo100M | **WAM 独有优势** — 无需动作标签即可学习物理常识 |

### 4.5 WAM 的评估体系（三级）

1. **视觉保真度**：PSNR, SSIM, FVD, DINO 相似度
2. **物理常识**：物体动力学、碰撞精度、流体行为
3. **动作可行性**（决定性层级）：仿真 + 真实机器人任务成功率、跨具身泛化

## 五、VLA vs. WM vs. WAM 核心对比

| 维度 | VLA | World Model | WAM |
|------|-----|-------------|-----|
| **建模目标** | P(a \| o) | P(o' \| o, a) | P(o', a \| o) |
| **核心能力** | 反应式映射 | 内部推演 | 预测 + 执行统一 |
| **是否输出动作** | ✅ | ❌ | ✅ |
| **是否预测未来** | ❌ | ✅ | ✅ |
| **数据需求** | 大量机器人标注数据 | 视频即可（免动作标签） | 异构数据混合 |
| **推理速度** | 10-50 Hz | 较慢（需多步展开） | ~7-10 Hz（优化中） |
| **可解释性** | 低 | 高（可视化预测） | 中-高 |
| **代表工作** | RT-2, OpenVLA, π₀ | DreamerV3, Cosmos | GR-2, DreamZero, CoVAR |
| **成熟度** | 较成熟 | 成熟 | 新兴（2025） |

## 六、WAM 是否属于底层架构？

**是的，WAM 是具身智能的一种新兴底层架构范式**，理由如下：

1. **有独立的建模目标**：P(o', a \| o, l) — 联合预测未来和动作，既不同于 VLA（仅 P(a\|o)），也不同于 WM（仅 P(o'\|o,a)）

2. **有完整的架构分类学**：级联式 vs 联合式，自回归 vs 扩散，统一流 vs 多流 — 构成系统的设计空间

3. **有独立的训练范式**：能够混合四种异构数据源（尤其是利用无动作标签的自我视频），这是 VLA 做不到的

4. **有独立的评估体系**：三级评估（视觉保真度 → 物理常识 → 动作可行性）

5. **有社区共识**：2025-2026 年出现了专门的综述论文（如复旦团队 "World Action Models: The Next Frontier in Embodied AI"），HuggingFace 设有 WAM 论文专区

**WAM 的定位**：

```text
VLA (响应式)  ──→  WAM (预测式)  ──→  ??? (认知式)
  2022-2024          2025-新兴          未来
```

WAM 被视为具身智能从"反应式控制"走向"预测式智能"的关键架构跃迁。

## 七、架构演进路线图

```text
2018-2020: RL/IL 时代
  ├── PPO, SAC, BC
  └── 纯从零训练，泛化弱

2021-2022: 视觉基础模型 + 模块化
  ├── SayCan (LLM规划 + 可行性评估)
  ├── PerAct (点云 + 语言)
  └── 模块独立优化，误差累积

2022-2024: VLA 时代
  ├── RT-1 → RT-2 → RT-X
  ├── OpenVLA, Octo, π₀
  ├── TrackVLA (EVT 领域)
  └── 端到端，强泛化，但无预测能力

2024-2025: World Model 增强
  ├── DreamerV3, TD-MPC2
  ├── Cosmos, Sora
  └── 能推演后果，但不直接输出动作

2025-至今: WAM 统一
  ├── GR-2, DreamZero, CoVAR
  ├── TrackVLA++ (Polar-CoT + TIM)
  └── 预测 + 执行统一，异构数据混合训练
```
