## 0. 一句话与总因果图

**当前最硬的瓶颈:闭环成功率 SR = 0**,且已定位其根因链 —— **不是单一模块,而是"取景(控制)× 在线认车(grounding)"两条链耦合卡死**,两者都是中等投入、非快修。

```
SR = 0
  └── tid 每集"承诺错车 ≥2s"(success 判据) ← 【瓶颈①在线 grounding】
        └── 在线认车 mis_follow ~0.74(离线仅 0.58) ← 帧 OOD
              └── 目标 off-center 92% / 远 50% / 候选 N6 拥挤 41% ← 【瓶颈②取景/控制】
                    └── DiT 跟踪比专家松(BC covariate shift)
  ※ 对照:目标居中+近距的帧,在线 grounding ≈ 离线 0.50(认车头本身没问题)
  ※ 上界:专家取景 → SR 0.11(任务可解);DAgger 同分布 → grounding 0.39(分布可学)
```

## 2. 逐条详解(含证据与边界)

### ① 在线 grounding 差 + 离线优化不迁移 —— **当前最关键**
- **现象**:离线 tid mis_follow 0.58,闭环 0.74;所有离线 grounding 优化(换损失 ce/margin/hardneg、加容量 d512/h8、CLIP 式 attrbind 0.51→0.44)**在闭环全部无效**(都塌到 0.74)。
- **根因(已严格排除到)**:**不是**轨迹协变量、**不是**未见地图(Town05 训练见过)、**不是**未见场景配置(训练 seed 6030 也 0.74)、**不是**在线特征失真(parity cos≥0.999)、**不是** `<unk>`(词表覆盖 OK)。**是"离线评测 vs 在线闭环评测"本身**:闭环帧更难(off-center/远/N6 拥挤),离线均匀抽帧偏易。
- **可修性证据**:DAgger 在闭环帧上 fine-tune,**同分布 mis_follow 0.70→0.39** → 头能学会闭环帧,是**分布覆盖**问题,不是特征墙。
- **卡点**:success 直接依赖 tid 承诺 → grounding 0.74 → 每集承诺错车≥2s → SR=0。

### ② 闭环取景分布 ≠ 训练分布 —— 与①耦合(⚠️ 表述已更正,见下"设计张力")
- **现象**:即使 cv_gated(GT 种子、飞向真目标),目标仍 **off-center 92%、远 50%、N6 拥挤 41%**;闭环 off-center grounding 0.74 vs central 0.50。
- **决定性证据**:用**专家控制**(GT+PID 居中)驱动 + tid 打分 → **SR 0→0.11(首次非零,任务可解)**、mis_follow 0.72→0.59、居中率 0.12→0.31。
- **⚠️ 设计张力(2026-08-30 更正)**:**off-center 是前期为去"中心位置捷径"(v4)特意设计的**——让模型必须靠语言而非"跟中心"。因此:
  - "改善取景 = 让 DiT 把目标居中"是**错误修法**:它**重新引入被去掉的中心捷径**(居中→中心候选=目标),与去相关设计冲突,且依赖 GT 不可部署。**作废。**
  - **直证(2026-08-30,离线 by-central 分层,同中心30%框口径)**:离线 central **0.462**(占50%)/ off-center **0.695**(占50%);闭环 central 0.50 / off-center 0.74(占**92%**)。→ **同一档难度几乎一样(off 0.695 vs 0.74,仅 +4pp)——我原先"极端 OOD 难度"基本不成立**;真正差异是**频率**:闭环 92% off-center vs 离线 50%。
  - **真相**:**off-center 本身就内在难(~0.70),且训练里已有(50%)、训过仍 0.70 = 去中心捷径(v4)的内在代价**(边缘/偏角/小 → 特征受限);闭环让无人机自然地 92% 时间把目标放边缘 → **把本就难的 off-center 从 50% 放大到 92%** → 整体 0.74。不是"闭环制造更极端 off-center",是"闭环放大 off-center 的频率"。
- **attrbind by-central 收尾(2026-08-31)**:换更强的头**能压 off-center**(xattn 0.692→attrbind 0.560,−0.13,与 central 同幅);**但 off−central 惩罚 ~0.23 换头不变**(xattn 0.232/attrbind 0.238)→ **off-center = "头可改部分" + "头无关的 ~0.23 特征惩罚"双重**。且 attrbind 离线增益**不迁移闭环**(闭环仍 0.74)。
- **对修法的精确结论(三层叠加,无单一便宜修)**:(a) **头可改**——但离线增益不迁移闭环;(b) **~0.23 固定特征惩罚**(边缘/偏角/小)→ **分辨率/更强边缘-小目标表征**;(c) **闭环频率放大**(off-center 50%→92%,去捷径×松跟踪)。**"居中"仍禁**(重引入捷径)。→ 真正治本 = 分辨率/表征 + 在线分布鲁棒训练,中等以上投入;换头/DAgger/加数据都不彻底。

### ③ 反应式单帧无法预测出画位置(EAR/WHERE)
- **现象**:EAR 出画预测 FDE 丢失帧 58–90m,**公平重训 ≈ 欠训**(不是训练问题,是单帧极限),连速度无关 persist(17.6m@6s)都远不如。
- **已缓解**:**记忆+CV 先验**(`ex_source=track/cv_gated`)闭环把 track_seconds 22→63s、真目标重捕 0.38→0.48;**直路 CV 10-23m 够用,转向 47m 崩** → WM 只对**转向/路口**有据。
- **残留**:WM 未建;转向数据欠采样(见④)。

### ④ 长丢失+转向数据欠采样
- P1 数据(5-15s 主动长丢失 + 专家直飞拦截演示 + 目标重现 + 重现处 ≥2 look-alike 共视)**未生成**;转向丢失帧 n=20-27,**连评测都不稳,更训不动 WM**。
- `is_junction`/车道拓扑标注(纯补标注、不重渲染)可同时服务转向分层 + WM 路网 GT。

### ⑤ DAgger 数据量不足
- 首轮 DAgger:12 集 × `s2_period=6` = **仅 880 训练帧** → 过拟合那 12 场景;fresh-seed 0.69(比 offline 0.58 还差),offline-val 也 0.44→0.48 退化。
- **修法**:`s2_period=1` 每帧记 + 25+ 集 → ~万帧 + offline replay + 温和 lr;这是①落地的前置。

### ⑥ 离线指标不预测闭环(方法学风险)
- 整条线反复出现:**离线动、闭环不动**。离线 mis_follow(0.58)是**乐观代理**,真实在线难度 0.74。
- **纪律**:grounding 的评测/选型**以闭环 mis_follow 为准**,不被离线数迷惑(否则重蹈 attrbind 覆辙)。

### ⑦ success 判据偏严 / ⑧ 场景密度 / ⑨ grounding 天花板
- ⑦ 单次承诺错车 ≥2s(整段 ~90s)即失败:0.74 认车下每集必触发 → SR=0。可考虑重定 t_fail 或更强承诺迟滞(但迟滞救不了持续 4-19s 的错误承诺)。
- ⑧ 在线 41% 帧 N=6(离线 ~12%):评测场景比训练拥挤 → grounding 更难。
- ⑨ 语言 grounding 本身有天花板(有语言 58% 非 0%,共视 look-alike + VLM 细粒度上限);tier-c 0.70。

## 4. 优先级建议(修法 × 依赖)

**关键路径(冲 SR)= ⑤密采 → ①DAgger-at-scale(治在线grounding) ‖ ②改DiT取景(治OOD上游);两者叠加才可能 SR 明显 >0。**

> **⚠️ 2026-08-30 直证后再排序**:by-central 直证显示 off-center 认车 **内在难(~0.70,训练已含50%)**,闭环靠 92% 频率放大它。→ **DAgger/加数据的天花板≈0.70(特征受限),被下调;真正治本的"边缘/小目标特征表征(分辨率)"被上调。**

- **短期便宜/诊断**:⑥ 评测纪律(以闭环为准);先跑 attrbind by-central,确认换头能否压 off-center 的 0.70(便宜);
- **中期(治本方向)**:**提分辨率 / 更强边缘-小目标身份表征**(治 off-center 特征根因,⑧⑨);④ P1 数据 + is_junction(为 WM);
- **辅助**:① DAgger-at-scale(有上限,补分布但难破 0.70)、③ WM 路网(仅转向);
- **改善自然跟踪**(不居中但别甩太偏 → 降 92% off-center 频率)——微妙,需不重引入位置捷径。

**⚠️ 不做**:靠"让 DiT 居中"改善取景——重引入被去掉的中心位置捷径(v4),违背去相关设计。
**诚实边界**:off-center 认车 ~0.70 是去捷径的内在代价;专家(GT)居中上界也只 SR 0.11 → SR 从 0 到"可用"是**多轮工程 + 可能需分辨率/表征突破**,不是单点。

## 5. 论文可用的诚实结论(即便不再深投 SR)

这条调查线本身产出了扎实的方法学发现,可独立成文:
1. **语言必要性 H0 干净证成**(分辨率墙是真瓶颈,非数据/头);
2. **离线↔在线指标 gap**:离线 grounding 指标不预测闭环,是乐观代理;
3. **取景 × grounding 耦合**:闭环认车难度由控制的取景质量上游决定(central 帧 grounding = 离线);
4. **SR 因果链**:SR 被"tid 承诺错车≥2s"卡,而这由取景×在线grounding共同决定;两者单独都不充分(专家取景 SR 仅 0.11)。
5. **严谨方法学**:一系列"假瓶颈"的系统排除本身是贡献(covariate shift 拆解、offline-proxy 陷阱)。
