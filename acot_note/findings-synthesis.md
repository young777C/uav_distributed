# ACoT-UAV-Track 研究发现系统梳理

> 2026-08-31 · 从"知识视角"归纳整条调查线的**发现与证成**(问题视角见 `research-bottlenecks.md`)
> 任务:无人机语言指定目标车 → 出画后 **预测-拦截-重捕获**;SR = 整段跟对被指目标不失守。

---

## 0. 研究框架:三轴分解

把任务拆成三个可分别测量的能力,是整条线的方法论骨架:

```
出画重捕获成功 (SR)
  = WHERE(预测目标去向、飞去拦截)
  × WHICH(重现时在 look-alike 里认对车)
  × 取景(控制把目标框成"可认"的样子)
```

**这个分解本身是第一个贡献**:它让"SR=0"这个笼统失败可以被逐轴归因,避免在错误的地方投入。

---

## 1. 核心发现(按轴 × 时间弧)

### 轴一 · WHICH-离线:语言必要性干净证成(里程碑)
| 发现 | 证据 |
|---|---|
| **语言是 load-bearing 的** | 去尽几何捷径 + 512px 后:有语言 **58%** vs 无语言 **72%**(chance 76%),稳定 gap ~13pp |
| **真瓶颈是图像分辨率**,不是数据/头 | v3(深度)/v4(居中)逐个去捷径后卡 chance;**唯一变量分辨率 336→512(车 12→27px)一改翻盘** |
| **判据要用 in-distribution 探针** | 身份可读性 by-episode 6% 但同分布 55% → 27px 特征富含身份,VLM 预训练 grounding 可迁移 |
| **指标净化是前提** | mis_follow 曾被 argmax 平局 × target 恒 idx0 做假;候选打乱后诚实 |

### 轴二 · WHERE:反应式单帧的物理极限 + 便宜先验的价值
| 发现 | 证据 |
|---|---|
| **单帧模型根本无法预测出画位置**(架构极限,非欠训) | EAR 丢失帧 FDE 58–90m;**公平重训 ≈ 欠训**;连速度无关 persist(17.6m@6s)都远不如 |
| **零训练的"记忆+匀速(CV)"先验碾压 EAR** | 直路 CV 10–23m;但**转向崩到 47m** |
| **→ WM(路网预测)只对"转向/路口"有据** | CV 直路够用,只有弯道/分叉需要结构预测 → 精确界定了 WM 的价值区,避免过早堆复杂度 |
| **WM 机制离线证成(H7,正向结果)** | 同起点(oracle-当前)下**沿车道 road vs 直线 cv_frame**:转向/路口 FDE 降 **20–56%、随视界增长**(loss_junction 9.3→4.1@6s),直路 road≈cv_frame(无副作用)→ **路网结构本身有用**。诚实边界:road_pred 是 oracle-当前 = 机制上界,**可部署增益待 P2a-1 闭环**(`runs/ladder_road_0831_0818.log`) |

### 轴三 · WHICH-在线 & SR:闭环揭示的真相(本线核心)
| 发现 | 证据 |
|---|---|
| **补好 WHERE 反而暴露 WHICH 是闭环墙** | 记忆+CV 先验(Plan A)把 track_s 22→63s、真目标重捕 0.38→0.48,**但 SR 仍 0、lock_wrong↑** |
| **离线 grounding 优化全部不迁移闭环** | 换损失(ce/margin/hardneg)、加容量(d512/h8)、CLIP 式 attrbind(离线 0.51→0.44)——**闭环全塌到 0.74** |
| **SR 被 grounding × 取景"耦合"卡**(非单一) | cv_gated **完美 WHERE 仍 SR=0**(100% 因 tid 承诺错车 ≥2s,9/10 集跑满、目标在框内);**专家取景 → SR 0.11(任务可解)** |
| **off-center 认车的三层代价** | 离线 central 0.46 / off 0.69;换头(attrbind)能压 off 0.69→0.56 **但不迁移闭环**;off−central 惩罚 **~0.23 换头不变**(边缘/小特征);闭环 off-center **50%→92%**(松跟踪放大) |

## 1.5 重定向(2026-08-31 里程碑):**真墙是 WHICH-under-reacquisition,不是 WHERE;WM 已证不足**

WM(P2a)整条线跑完后,所有闭环证据收敛到一个更根本的事实——**详见 memory `acot-uav-reid-reframe`**:

**已证实(WHERE 不是瓶颈,WM 撬不动 WHICH)**:把 WHERE 从烂→近乎完美(ear→cv_gated→road→**road_oracle**),track_seconds 24→65s,但 **SR 恒 0、reacquire_lock_wrong 恒 ~0.74 四臂一致**。road_oracle(近乎完美 WHERE)仍 SR=0 → **"即便 WM 建好弯道、有效跟踪,仍在重现点认错车"**。CV 已把 WHERE 对闭环的贡献吃满;WM 不赚复杂度。

**强推断(单帧 grounding 范式是上限)**:重捕获 = look-alike 里的 **re-识别** = **时序关联 + 外观记忆**问题,非单帧分类。tid 头问"哪辆最贴描述"(look-alike 都部分满足),而非"哪辆是我一直跟的那一辆"。三条独立证据:①离线 grounding 优化全不迁移闭环(在线卡 0.74);②专家取景(完美 WHERE+框正)→ SR 仅 **0.11**;③单帧+语言 mis_follow 仅 ~0.58(chance 0.76)。

**时序外观记忆 re-ID 实验结果(2026-09-01,cv+reid vs cv+xattn,同 WHERE 只差 WHICH)**:
| 指标 | xattn(语言) | reid(外观记忆) | Δ |
|---|---|---|---|
| mis_follow | 0.703 | **0.568** | **−0.135 显著** |
| reacquire_success | 0.547 | 0.629 | +0.082 |
| SR | 0 | **0** | 0 |

**reframe 方向证实**:时序外观 re-ID 显著优于单帧语言认车(mis_follow −0.135 显著)→ 重捕获确是外观关联问题。**但 SR 仍 0**:0.57 太高(SR 要整段无 2s 认错),且这是 **oracle-seeded**(模板取自可见时 GT)最好情况——连它都只到 0.57 → 残差是**外观特征在 look-alike 间不够可分**。(注:reid 在 cv_gated 下是 score-only,track_seconds 差是采样 variance 非 reid 效应。)

### 收敛结论(整个 investigation 统一到一个根因)
- **WHERE**:CV 就够,WM 不加分(road_oracle 近乎完美 WHERE 仍 SR=0);
- **WHICH**:时序 re-ID > 单帧语言(新证实);
- **两者最终卡在同一处**:**look-alike 外观特征在当前分辨率下不够可分**(离线语言必要性的分辨率墙 + 这里 oracle-reid 的 0.57 天花板 = **独立两条证据指向同一根因**)。
→ **SR 的真正钥匙 = 外观可分性(分辨率/边缘表征)**,无论走语言还是 re-ID。WM(WHERE)与 grounding-头/re-ID 机制本身都不是根因。详见 memory `[[acot-uav-reid-reframe]]`。

## 2. 方法学发现(元层面 —— 可能是最扎实、最可迁移的贡献)

### 2.1 离线↔在线指标 gap(核心方法学发现)
- **离线 mis_follow(0.58)不预测闭环(0.74)**,是**乐观代理**;
- 一切离线上有效的 grounding 改进,闭环全无效 →**grounding 的评测/选型必须以闭环为准**;
- 机理:闭环帧分布(off-center 92%/远/N6 拥挤)与离线均匀抽帧不同,且**离线优化的是那个较易的分布**。

### 2.2 系统排除"假瓶颈"(一整套 covariate-shift 拆解)
| 曾怀疑 | 检验 | 结论 |
|---|---|---|
| 语言不必要 | H0 净化+去相关+512px | ✗ |
| EAR 欠训 | 公平重训 | ✗(单帧极限) |
| grounding 换损失/加容量 | ce/margin/hardneg、d512/h8 | ✗(噪声内) |
| 闭环差=分辨率墙 | 属性可读性探针(color 53%) | ✗(特征含身份) |
| 闭环差=学生轨迹协变量 | cv_gated≈track≈ear | ✗(轨迹无关) |
| 闭环差=未见地图/场景 | Town05 训练见过、seed 6030 也 0.74 | ✗ |
| SR 被纯控制卡 | cv_gated 100% 因认车错失败 | ✗(grounding×取景耦合) |
| off-center=极端 OOD | by-central 直证 | ✗(同档仅+4pp,主因是频率) |

**这套"逐一证伪"本身是贡献**:示范了如何把"闭环差"这个笼统现象拆到可归因的根因。

### 2.3 去捷径的内在代价("去偏 vs 可学性"张力)
- 为破"跟中心"捷径(v4)特意让目标 off-center;
- **代价**:目标偏离中心 = 边缘/偏角/小 → **认车内在更难(~0.23 固定惩罚,换头不变)**;
- **普适启示**:去除捷径/去偏,往往以"任务本身变难"为代价;闭环控制会进一步**放大**这个难区的频率。

### 2.4 实验严谨的教训 → 已固化护栏
- 反复的参数不一致(lr/s2_period/fov)+ 结论过早 → 立 **4 护栏**:参数继承/OFAT、正对照、假设vs已测标注、长跑预检(挂载日志/shm/smoke)。见 memory `acot-uav-experiment-rigor`。

## 3. 能力边界:证成 vs 未解

**已证成(可写入论文的确定结论)**
- 语言必要性(H0,分辨率是真瓶颈);
- 单帧反应式无法预测出画(架构极限);记忆+CV 先验有效且价值区=直路;
- SR 因果链:SR ← tid承诺错车≥2s ← 在线grounding 0.74 ← off-center帧 ← 取景;
- off-center 认车的三层代价(头/特征/频率)。

**未解(需中等以上投入)**
- **SR > 0**:需 **分辨率/更强边缘-小目标表征** + **在线分布鲁棒训练(DAgger at scale)**,且专家上界也只 0.11;
- **WM 未建**(转向预测);**P1 长丢失+转向数据缺**。

## 4. 对研究定位 / 论文的启示

**三类可发表的贡献**
1. **语言必要性 + 空间智能**:H0 干净证成 + "去捷径需要高分辨率"的洞察;
2. **闭环方法学**:offline↔online gap、取景×grounding 耦合、去捷径代价、一整套假瓶颈排除 —— **这套诚实的闭环拆解方法学,独立价值可能高于 SR 数字本身**;
3. **系统与工具**:双容器闭环 harness + 一系列诊断工具(`intercept_eval`/`baseline_deadreckon`/`grounding_probe`/`grounding_head_compare`)+ 记忆+CV 先验 + DAgger 管线。

**诚实边界(必须在论文里如实写)**
- SR 从 0 到"可用"是**多轮中等工程 + 可能需分辨率/表征突破**,非单点;
- 离线指标对闭环是乐观代理;
- 去捷径设计有内在认车代价。

## 附:一句话记住每个发现

- 语言有用,但要够高分辨率才看得清身份;
- 单帧看不到未来,记忆+匀速比模型强(直路);转弯要路网;
- 补好"去哪"反而暴露"是哪辆"才是闭环的墙;
- 离线刷分不算数,闭环才算;
- 认不对车 → 承诺错车≥2s → 每集失败(SR=0);
- 认车难,一半怪"没框好(取景)",而"框好=居中"又会重引入被去掉的捷径;
- off-center 是去捷径的内在代价,换头能压一点、但闭环兑现不了、且有 0.23 的特征硬底;
- 真正的钥匙在"边缘-小目标的特征表征(分辨率)"和"在线分布鲁棒训练",都是中等以上投入。
