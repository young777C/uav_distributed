# 数据修复规格：使 H0 可检验(破除捷径 + 造断裂 + 提共视)

> 2026-07-29 | 给数据生成侧 | 依据：`experiment-design.md` §2.0(H0 四条件)、`training-plan.md` §当前状态、memory `acot-uav-benchmark-leak`
> 验收工具：`python -m train.benchmark_leak_probe --config train/config.yaml --split val`

## 0. 目标：让 H0 四条件全部成立

H0 成立 ⟺ (a) 无持续首帧 bbox 锚(语言-only 指定) ∧ (b) 目标身份 ⊥ 位置/几何 ∧ (c) 目标身份 ⊥ 时空连续性 ∧ (d) ≥2 语言可分、外观/运动不可分的干扰车共视足够。

**当前状态(2026-07-29 实测)**：

| 条件 | 状态 | 归属 |
|---|---|---|
| (a) 语言-only 指定 | 🟡 实现满足,**设计文档违反**(§2.1/§3.1 列了 bbox 输入) | 文档侧(改设计文档,非本规格) |
| (b) 身份 ⊥ 位置 | 🔴 **不满足**(纯几何分类器 ~3-5%) | **数据侧(§2)** |
| (c) 身份 ⊥ 连续性 | 🔴 **未设计**(无断裂事件;闭环未建) | **数据侧(§3)** |
| (d) 相似干扰共视 | 🟡 外观不可分✓,**共视偏低 ~14%** | **数据侧(§4)** |

本规格覆盖数据侧 (b)(c)(d);(a) 在设计文档处理。

## 1. 问题量化(已实测)

正式 w/o-language 消融(3 seed,困难子集 ≥2 候选)：**有语言 6.16%±1.81 ≈ 无语言 6.23%±1.12**,语言无可测贡献。根因分解:

| 捷径来源 | 困难子集 mis_follow | 判定 |
|---|---|---|
| 随机 / 最居中 / 最近 | ~70% / 53% / 19% | 参照 |
| **位置**(纯几何:u,v,depth+排名) | **~3-5%** | 🔴 主导捷径 |
| **外观**(cand_feats,无语言) | ~4.5-12%(不优于几何) | 🟢 无额外泄漏 |

**结论:捷径几乎全是位置。** 外观已达标(相似干扰车确实视觉难分,符合设计意图)。

---

## 2. 修复 (b)：目标位置与"它是目标"去相关

**原则:任何候选车占据任一几何位置的概率,与它是否为目标无关。**

采样规则(数据生成侧):
1. **位置槽随机化**:目标等概率出现在各方位(左/中/右)、各深度(近/中/远)、各相对排名——不再恒居中央/正前方。
2. **干扰车共享同一分布**:干扰车与目标从**同一位置/深度分布**采样;有时干扰车最居中/最近,目标在边上。
3. **打破排名规律**:目标占据"第几名最居中/最近"均匀分布。
4. **保持可见性**:目标大部分时间在画面内(可监督),但画面内位置随机。

**验收(硬门槛)**:`benchmark_leak_probe` 的纯几何 floor 从 ~5% **升到接近随机(~60-70%)**;trivial(最居中/最近)也应接近随机。

## 3. 新增 (c)：长时间丢失 + 预测-拦截重捕获(时空连续性断裂)

**为什么**:即使初始位置去相关,闭环里模型只要第 1 帧锁对,之后纯靠**视觉/运动连续性**跟到底,整段不读语言(TrackVLA++ 机制)。**必须制造断裂,使 re-acquisition 只能靠语言 + 预测。** 而**空中无路网约束 → 可直飞预测拦截点抄近路重捕获**,这是地面跟踪做不到的差异化能力(强化 EAR/H1 卖点)。

**现状(实测)**:`target/tx,ty,tz` 全程有效(出画期间仿真器仍记录目标 3D 位置 → **"预测出画目标未来位置"的监督标签已存在**);但当前丢失太短(最长 ~2.0s / 0-2% 帧)→ 该能力既未训练也无法评测。

### 3.1 数据生成侧
1. **拉长丢失时长**:丢失从 ~2s 拉到 **5-15s+**;每集 **≥1-2 次**长丢失事件 —— (i) 拐弯出画;(ii) 建筑/车辆**完全遮挡**;(iii) 与 look-alike 干扰车**轨迹交叉**后紧邻;(iv) **出画后重入**。**目标必须重现**(不是丢了就结束 episode)。
2. **专家演示"拦截"而非"盲跟/放弃"**:数据生成的专家(PID,有目标 GT 特权)在丢失期间必须**飞向目标已知的未来 3D 位置**(抄近路拦截),在目标重现处重捕获 —— **绝不能**结束 episode,也**绝不能**无依据盲跟。BC 只能学专家演示的行为,所以专家策略必须先具备拦截。
3. **重入时保证 ≥2 相似车共视**:目标重现时画面里同时有 look-alike 干扰车 → 重捕获必须靠语言区分(而非"哪辆刚出现就是它")。
4. **标注**:显式标记 **丢失段** 与 **重捕获帧(重现后 N 帧)**(用 `annotation/{occluded,off_screen}` + `target/t*` + `distractors/positions` 可复算或新增字段),供 E5 与"重捕获成功率 vs 丢失时长"评测切片。
5. **交叉时避免身份泄漏**:交叉前后目标不要恒居某一相对位置(否则又退化成位置捷径)。

### 3.2 标签/训练侧的关键反转(⚠️ 需改训练代码)
当前 `action` 损失在**不可见帧被 `visible` mask 掉**(设计原则"不盲跟",`stage2.py::action_flow_loss`)。长丢失场景要**区分两种不可见行为**:
- **盲跟**(坏,继续 mask):无依据直行;
- **预测-拦截**(好,**要监督**):飞向 EAR 预测的目标未来位置 —— 专家的拦截动作(用 GT 算)就是这段动作标签。

→ 训练侧改为:**在"专家演示拦截"的丢失帧上恢复 action 监督**(拦截标签),仅在真正无依据的帧继续 mask。EAR 的 waypoint 监督在丢失期间本就有效(`target/t*` 存在),已在训练"预测未来目标位置"。

### 3.3 短/长丢失 spectrum(避免走偏)
- **短丢失(拐弯,<6s)** → 现有 **EAR waypoint + staleness 复用** 机制本就对得上(S2 在最后可见帧的预测延伸进丢失期);主打场景。
- **长丢失(>6s,去向不确定)** → 需**目标状态记忆 / 延长 EAR horizon**(架构含义,见 design doc);拦截不可靠时 **search_mode + 语言重捕获** 兜底。
- 数据要覆盖整个 spectrum,别只造一种。

**验收(需闭环 harness,见 §6)**:
- E5 —— 只在**重捕获帧**上,w/o-language mis_follow **大幅高于** with-language(连续性失效 → 只剩语言 + 预测);
- **新指标**:重捕获成功率 vs 丢失时长 T 曲线;拦截效率(直飞预测位置 vs 反应式跟随)。
- 若断裂后也不掉点 → 数据无"语言唯一可分"事件,须继续加难。

## 4. 修复 (d)：提高 look-alike 共视率

**现状**:look-alike 共视仅 ~14% 帧 → 即使 gate 过,统计功效弱。外观维度已达标(无需动)。

数据生成侧:
1. **提共视率**:目标 target 提到 **≥40-50% 帧有 ≥2 辆 look-alike 干扰车同时在画面内**(same_shape_diff_color / same_color_diff_shape 档)。
2. **离屏平滑回收**(数据卡 §6.2):干扰车驶出视野后平滑召回,维持共视,而非一去不返。
3. **更多并行/交叉**:增加与目标同类、同向行驶的相似车。
4. 保持"语言可分、外观/运动不可分":颜色/车型语言描述能区分,但视觉/运动难分(已达标,勿破坏)。

**验收**:难例子集(≥2 look-alike 共视)帧数显著增加,足以给 3-seed × bootstrap CI 提供功效。

## 5. 统一验收标准(H0 gate 全过才算 well-posed)

| 证据 | 判据 | 依赖 |
|---|---|---|
| leak_probe 纯几何 floor | ~5% → **~60-70%(接近随机)** | 离线,即时 |
| E1 w/o-language(难例子集) | mis_follow **显著↑**(≥2× 且 CI 不重叠) | 离线 |
| E2 外观/运动-only 基线 | 明显高于完整模型 | 离线 |
| E4 难例子集功效 | 难例帧数足够 | 离线 |
| **E5 断裂后重捕获** | 断裂后 w/o-language mis_follow **大涨** | **闭环 harness(待建)** |

## 6. 协调边界与依赖

- **数据侧(数据生成 agent)**:实现 §2(位置去相关)、§3(断裂事件+标注)、§4(提共视)。§2 见效最快、优先。
- **训练侧(本 agent)**:提供 `benchmark_leak_probe` 作 (b) 验收门;数据改好后复跑 3-seed 语言消融(E1/E2/E4);基建已就绪(mmap+workers 可 8 卡快速重训)。
- **(c) 的验收 E5 依赖闭环 rollout harness**(experiment-design §7,当前**待建**)——离线逐帧测不了连续性捷径。**(c) 的数据可以先造,但验收要等 harness**。
- **(a)** 是设计文档修复(删 §2.1/§3.1 的 bbox 输入),不在本规格。

## 7. 建议顺序

1. **先 (b)**(位置去相关)—— 见效快、离线即可验收,解开当前离线 gate 的死结。
2. **并行 (d)**(提共视)—— 提升统计功效,离线即可验收。
3. **(c)**(断裂事件)—— 数据可先造,但**验收 E5 需先建闭环 harness**;与 §7 harness 工程并行。
4. 三者齐备 → H0 四条件全满足 → 任务 well-posed → 进主实验。
