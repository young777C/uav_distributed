## 2. 修复 (b)：目标位置与"它是目标"去相关

**原则:任何候选车占据任一几何位置的概率,与它是否为目标无关。**

采样规则(数据生成侧):
1. **位置槽随机化**:目标等概率出现在各方位(左/中/右)、各深度(近/中/远)、各相对排名——不再恒居中央/正前方。
2. **干扰车共享同一分布**:干扰车与目标从**同一位置/深度分布**采样;有时干扰车最居中/最近,目标在边上。
3. **打破排名规律**:目标占据"第几名最居中/最近"均匀分布。
4. **保持可见性**:目标大部分时间在画面内(可监督),但画面内位置随机。

**验收(硬门槛)**:`benchmark_leak_probe` 的纯几何 floor 从 ~5% **升到接近随机(~60-70%)**;trivial(最居中/最近)也应接近随机。

## 3. 新增 (c)：长时间丢失 + 预测-拦截重捕获(时空连续性断裂)

**为什么**:即使初始位置去相关,闭环里模型只要第 1 帧锁对,之后纯靠**视觉/运动连续性**跟到底,整段不读语言(TrackVLA++ 机制)。**必须制造断裂,使 re-acquisition 只能靠语言 + 预测。** 而**空中无路网约束 → 可直飞预测拦截点抄近路重捕获**,这是地面跟踪做不到的差异化能力(强化 EAR/H1 卖点)。

**现状(实测)**:`target/tx,ty,tz` 全程有效(出画期间仿真器仍记录目标 3D 位置 → **"预测出画目标未来位置"的监督标签已存在**);但当前丢失太短(最长 ~2.0s / 0-2% 帧)→ 该能力既未训练也无法评测。

### 3.1 数据生成侧
1. **拉长丢失时长**:丢失从 ~2s 拉到 **5-15s+**;每集 **≥1-2 次**长丢失事件 —— (i) 拐弯出画;(ii) 建筑/车辆**完全遮挡**;(iii) 与 look-alike 干扰车**轨迹交叉**后紧邻;(iv) **出画后重入**。**目标必须重现**(不是丢了就结束 episode)。
2. **专家演示"拦截"而非"盲跟/放弃"**:数据生成的专家(PID,有目标 GT 特权)在丢失期间必须**飞向目标已知的未来 3D 位置**(抄近路拦截),在目标重现处重捕获 —— **绝不能**结束 episode,也**绝不能**无依据盲跟。BC 只能学专家演示的行为,所以专家策略必须先具备拦截。
3. **重入时保证 ≥2 相似车共视**:目标重现时画面里同时有 look-alike 干扰车 → 重捕获必须靠语言区分(而非"哪辆刚出现就是它")。
4. **标注**:显式标记 **丢失段** 与 **重捕获帧(重现后 N 帧)**(用 `annotation/{occluded,off_screen}` + `target/t*` + `distractors/positions` 可复算或新增字段),供 E5 与"重捕获成功率 vs 丢失时长"评测切片。
5. **交叉时避免身份泄漏**:交叉前后目标不要恒居某一相对位置(否则又退化成位置捷径)。

### 3.2 标签/训练侧的关键反转(⚠️ 需改训练代码)
当前 `action` 损失在**不可见帧被 `visible` mask 掉**(设计原则"不盲跟",`stage2.py::action_flow_loss`)。长丢失场景要**区分两种不可见行为**:
- **盲跟**(坏,继续 mask):无依据直行;
- **预测-拦截**(好,**要监督**):飞向 EAR 预测的目标未来位置 —— 专家的拦截动作(用 GT 算)就是这段动作标签。

→ 训练侧改为:**在"专家演示拦截"的丢失帧上恢复 action 监督**(拦截标签),仅在真正无依据的帧继续 mask。EAR 的 waypoint 监督在丢失期间本就有效(`target/t*` 存在),已在训练"预测未来目标位置"。

### 3.3 短/长丢失 spectrum(避免走偏)
- **短丢失(拐弯,<6s)** → 现有 **EAR waypoint + staleness 复用** 机制本就对得上(S2 在最后可见帧的预测延伸进丢失期);主打场景。
- **长丢失(>6s,去向不确定)** → 需**目标状态记忆 / 延长 EAR horizon**(架构含义,见 design doc);拦截不可靠时 **search_mode + 语言重捕获** 兜底。
- 数据要覆盖整个 spectrum,别只造一种。

**验收(需闭环 harness,见 §6)**:
- E5 —— 只在**重捕获帧**上,w/o-language mis_follow **大幅高于** with-language(连续性失效 → 只剩语言 + 预测);
- **新指标**:重捕获成功率 vs 丢失时长 T 曲线;拦截效率(直飞预测位置 vs 反应式跟随)。
- 若断裂后也不掉点 → 数据无"语言唯一可分"事件,须继续加难。

## 4. 修复 (d)：提高 look-alike 共视率

**现状**:look-alike 共视仅 ~14% 帧 → 即使 gate 过,统计功效弱。外观维度已达标(无需动)。

数据生成侧:
1. **提共视率**:目标 target 提到 **≥40-50% 帧有 ≥2 辆 look-alike 干扰车同时在画面内**(same_shape_diff_color / same_color_diff_shape 档)。
2. **离屏平滑回收**(数据卡 §6.2):干扰车驶出视野后平滑召回,维持共视,而非一去不返。
3. **更多并行/交叉**:增加与目标同类、同向行驶的相似车。
4. 保持"语言可分、外观/运动不可分":颜色/车型语言描述能区分,但视觉/运动难分(已达标,勿破坏)。

**验收**:难例子集(≥2 look-alike 共视)帧数显著增加,足以给 3-seed × bootstrap CI 提供功效。

## 8. 【当前唯一阻塞】跟踪距离/深度去相关(2026-08-11)

> 这是 §2(b) 的**深度维度补全**。§2 把目标的**横向/方位**去相关了(floor 5%→41.6%),但**深度/框大小**仍系统性泄漏目标身份。把它堵上,离线 gate 才能过。

### 8.1 根因(精确)
UAV 专家以**近似固定的跟踪距离和高度**跟随目标 → 图像里:
- 目标的 **depth(到相机距离)** 恒在一个窄带;
- 因此目标的 **投影框大小(≈ f·车宽/depth)** 也恒在一个窄带;
- 干扰车散布在其它深度 → **"挑深度最典型 / 框大小最典型 / 最近"的那辆 = 目标"** 成立 ~58% → mis_follow floor 41.6%。

`benchmark_leak_probe`(config_full,2026-08-11)里 **`nearest` = 37.72%、几何 MLP floor ≈ 38-42%**,而 `chance` = 73.21%、`most-central` = 86.41% —— 横向 u,v 已被 §2 打散(目标甚至偏离中心),**唯独深度没打散**,这个残留深度信号就是当前 floor 的来源。

### 8.2 采样规则(数据生成侧)
**原则:目标的 depth / 框大小 / 深度排名,与"它是目标"统计独立。**

1. **随机化跟踪距离 + 高度**:专家跟踪距离在合理范围内**逐集(最好逐段)随机**(如 距离 8–40m、高度 15–60m 各档均匀),使目标 depth **覆盖宽分布**,而不是一个窄带。
2. **干扰车共享同一 depth 分布**:干扰车与目标从**同一 depth/框大小分布**采样;**必须频繁出现"干扰车比目标更近/更居中深度"** 的帧(目标不再恒是最近/最典型深度那辆)。
3. **打散深度排名**:目标是"第几近"应**均匀分布**(有时最近、有时最远、多数在中间),就像 §2.3 对横向排名的要求。
4. **可见性不牺牲**:目标大部分时间在画面内、框不至于太小而不可辨(设 box_min_px 下限);在这个约束内让 depth 尽量随机。
5. **别引入新捷径**:随机跟踪距离时,注意不要让"距离突变"与"重捕获/机动事件"绑定(否则又造出可预测的时序捷径),距离变化应平滑且与事件解耦。

### 8.3 验收(硬门槛)
- `benchmark_leak_probe`(困难子集):**`nearest` 从 37.72% → 接近随机(chance=73.21%)**,几何 MLP floor **从 ~38-42% → ~70%**。这是 (b) 完全达标的信号(横向已达标,补上深度即全达标)。
- 达标后复跑 3-seed 语言消融(E1):**有语言 mis_follow 应显著低于无语言**(此前一直重合,是因为有位置/深度捷径可走)。
- 顺带确认:`nearest`/`center` 等 trivial 基线都接近随机。

### 8.4 与其它节的关系
- §2(横向/方位)+ §8(深度)= (b) 完整达标 → 离线 gate 死结解开。
- §3(长丢失/拦截,已推进到 16.5s)与 §4(共视)继续;§3 的 E5 仍等闭环 harness。
- **补 h5 字段 `distractors/similar`(§4.1,仍未落地)** 是 (d) 精确切片的前置,请一并处理。

### 8.4b ⚑ mvp_full_v2 复核：dp 维度未改善(2026-08-12)
mvp_full_v2(67 集，带 `distractors/similar` + 高度随机化)跑 `benchmark_leak_probe`：**深度捷径没解决，反而略强。**

| 指标 | mvp_full(旧) | mvp_full_v2(新) | 判定 |
|---|---|---|---|
| `nearest`(=最优几何 floor 上界) | 37.72% | **31.30%** | ❌ 更可利用 |
| 目标深度 std（全帧 3D 距离） | 31.2 | 26.1 | ❌ 深度带更窄 |
| 目标是最近车（全帧） | 49.0% | 51.8% | ❌ 没变 |
| 相机高度 z std / 上限 | 12.8 / 68m | 9.9 / 52m | ⚠️ 高度反而更集中 |

- **注意**：probe 的 `OPTIMAL position-only MLP` 这次打印 47.00%，**不可信**——它高于 `nearest` 手写规则(31.30%)，而最优分类器必然 ≤ 任一手写策略，说明该 MLP 逐样本 SGD 欠拟合(naive 划分有集间分布差)。**以 `nearest` 作可信下界**：最优 floor ≤ 31.30%（旧 ≤ 37.72%）→ 更可利用。
- **根因**：这一版只随机化了**相机高度**（且 std 从 12.8→9.9、上限 68→52m，反而更集中），**没有随机化水平跟踪距离**。目标深度主要由**水平 follow distance** 决定；高度只改俯视角/pitch，几乎不动"目标离相机多远"。
- **必须补做**：§8.2 第 1 条的**水平跟踪距离随机化**（逐集/逐段在 ~8–40m 均匀）+ 第 2 条**干扰车共享同一深度分布、频繁比目标更近**。仅随机高度无效。验收仍为 `nearest` → 接近 chance(68.95%)。

### 8.5 给数据 agent 的一句话
**只做一件事就能顶过当前离线 gate:让专家跟踪距离/高度随机化、干扰车共享同一深度分布、目标不再恒是"最近/典型深度"那辆 —— 把 `nearest` 从 37.72% 打到接近随机(73.21%)。** 其余(横向、外观、共视)已达标或大幅推进。

## 9. 【当前唯一阻塞】关闭"居中"捷径(2026-08-14)

> 深度(§8)在 mvp_full_v3 已闭合,语言必要性 gate 首次通过(有语言 ~56% vs 无语言 ~71%,稳定 gap ~15pp)。但几何 floor 仍卡 **54%**,有语言臂也卡这——**唯一原因是残留的"居中"捷径**。关掉它,有语言臂能突破 54%、gap 进一步张开。

### 9.1 现象(实测 mvp_full_v3,困难帧 10465)
| 指标 | 值 | 含义 |
|---|---|---|
| `most-central` mis_follow | **54.5%** | "选最居中那辆"错 54.5%、**对 45.5%**(随机 chance=74%) |
| 目标归一化中心距(0=正中,1=角) | 中位 **0.22** | 目标很靠中心 |
| 干扰车归一化中心距 | 中位 **0.35** | 干扰车明显更偏外 |
| 目标是"最居中那辆"的比例 | **41.6%** | 远超随机 ~22% |
| 目标落在中心 30% 半径内 | 65% | 目标"通常居中",但干扰车也常居中,故只有 ~42% 判别力 |

**结论**:目标**系统性地比干扰车更靠画面中心**(中位 0.22 vs 0.35)→ "选最居中"就能蒙对 ~42% → 几何 floor 卡 54%。这是最后一个"目标身份 ⊥ 位置"未达标的维度(横向 §2 已达标,但**居中这一子维度被相机跟踪重新引入**)。

### 9.2 根因
**相机跟踪控制律把目标锁在光轴/画面中心。** UAV 相机始终瞄准目标 → 目标按定义落在画面中心附近;干扰车没被瞄 → 散在四周。大 standoff 尾随时,目标相对场景质心的横向偏移在远处被**角度压缩**,更显居中。**这是相机瞄准的副产物,不是场景性质**——所以横向世界坐标(§2)去相关了,画面居中却没有。

### 9.3 采样规则(数据生成侧)
**原则:目标在【画面】里的位置(u,v / 中心距),与"它是目标"统计独立。**

1. **相机瞄准加偏置/抖动**:不要把目标锁在画面正中。给瞄准点加一个**随机偏移**(逐段平滑变化),让目标的画面位置在合理可见范围内**铺开**(有时居中、有时明显偏左/右/上/下)。
2. **目标画面位置分布 ≈ 干扰车**:使目标的"归一化中心距"分布向干扰车看齐(目标中位从 0.22 抬向 ~0.35),即**目标不再系统性比干扰车更居中**。
3. **打散"最居中排名"**:目标是"第几居中"应**均匀分布**——频繁出现"某干扰车最居中、目标在旁边"的帧。
4. **保持可见性**:目标始终在画面内、框不过小(留边距,别抖出画面);在这个约束内让画面位置尽量随机。
5. **别引入新捷径**:瞄准偏移要平滑、且**与机动/丢失/重捕获事件解耦**(否则又造出可预测的时序捷径)。

### 9.4 验收(硬门槛)
- `benchmark_leak_probe`(困难子集):**`most-central` 从 54.5% → 接近 chance(74%)**;几何 MLP floor **从 54% → ~70%**;目标"最居中比例"从 41.6% → ~随机(~22%)。
- 达标后复跑稳定版 E1:**有语言臂应突破 54%**(现卡在 floor),gap 从 ~15pp 进一步张开。

### 9.5 一句话
**让相机瞄准别把目标钉在画面正中(加随机偏移),使目标的画面居中程度和干扰车一样 —— 把 `most-central` 从 54.5% 打到接近 chance。** 这是最后一个几何捷径,关掉后语言的价值才能完全显现。

## 10. 【分辨率墙】提高采集分辨率 + 收窄 FOV + 缩短 standoff(2026-08-14)

> mvp_full_v4 上几何三捷径已全关(chance 76%,几何 floor 距 chance 仅 6pp)、语言描述 100% 唯一(oracle 天花板 0%)。但 **E1 有语言臂仍卡 ~72%≈chance,语言几乎没被用上**。根因不再是场景,而是**分辨率**。

### 10.1 诊断链(实测,决定性)
1. **模型在 chance**:v4 有语言 ~72% vs 无语言 76%,gap 仅 ~4pp;
2. **任务可解**:目标完整描述("black Nissan Patrol SUV")在每个困难帧 **100% 唯一**,语言 oracle 天花板 = **0%**;
3. **身份不在特征里**:线性探针从 `cand_feats` 恢复**车型仅 12%**、颜色 23%(近 chance)——**VLM 缓存里就没保住每辆车的 make/body**;
4. **re-crop(B1)救不了**:从现有 336px 裁放大,总体仍 12%/23%;**只有 ≥20px 的框 make→57%、颜色→65%**,但 **94% 的候选是 <20px**,裁放大无中生有不出细节;
5. **根因 = 13px 车**:当前 FOV 90° + standoff ~54m + 336px → 4m 车只投影成 **~12px**(远端 ~6px)。10×10 网格(每格 33px)把 13px 车和背景池化成一坨 → 身份从像素层面就没了。

### 10.2 根因量化(采集几何)
```
车像素 ≈ f·车宽/depth,  f = W/(2·tan(FOV/2))
当前: FOV90°, 336px, standoff54m → 12.4px   (probe: make 不可读)
判据: 车 ≥20px 时 make 可读(57%)、颜色可读(65%);~40px make 舒适
```

### 10.3 修法(已定,数据侧 + 训练侧配套)
**A. 采集几何(数据侧):**
- **FOV: 90° → 70°**(适度变焦,不至于丢太多共视);
- **standoff: ~54m → 30-40m**(目标更近);
- **分辨率: 336 → 512px**(见 §10.4 文献依据)。

新几何下 4m 车像素(FOV70):

| 分辨率 | standoff30m | 35m | 40m | Qwen token(patch16×merge2) |
|---|---|---|---|---|
| 336 | 32 | 27 | 24px | ~110 |
| **512(选)** | **49** | **42** | **37px** | **256** |
| 672 | 64 | 55 | 48px | 441 |

→ **512px + FOV70 + standoff30-40 = 车 37-49px**,make 舒适、颜色稳。

**B. 训练侧配套(本 agent,已改):**
- config `image.width/height: 336 → 512`、`backbone.fov_deg: 90 → 70`;
- **`backbone.ctx_grid: 10 → 16`** —— 512px 原生网格是 16×16=256 token,ctx_grid=16 才能**保住这 256 个 token 不被又池化回 10×10**(否则升了分辨率又在缓存阶段把细节丢了)。见 `config_v5.yaml` / `config_v5_nolang.yaml`。

### 10.4 分辨率选 512 的文献依据
- **空中小目标数据集用高分辨率**:VisDrone 视频 3840×2160、图 2000×1500(正因目标小);UAV123 用低空 5-25m 换目标大;
- **机器人操作 VLA 用低分辨率**:OpenVLA 224×224(与 384 等效、快 3×)、TrackVLA 地面跟人 ~336 —— 因为目标又近又大;
- **我们踩在冲突上**:任务是"空中小目标"(该高分辨率),却抄了"机器人 VLA"的 336(低分辨率)。**336 是错的惯例来源。**
- **Qwen3-VL 原生支持动态分辨率**(SigLIP-2,896²=784 token),升分辨率不需换模型;512²=256 token,预计算/缓存成本仅约 **2.5×**,不浪费。

### 10.5 验收
- `cand_feats→属性` 探针:**车型从 12% → 显著上升**(目标 ≥40%),颜色 → ≥60%;
- 复跑稳定版 E1:**有语言臂突破 ~72% chance、明显低于无语言**,gap 从 ~4pp 放大到有意义的水平(≥15pp)。这是"语言承担全部消歧且模型真能用"的最终证据。

### 10.6 一句话
**场景已完美,但 336px 把 12px 车的身份从像素层面抹掉了。数据侧:FOV 70 + standoff 30-40m + 分辨率 512;训练侧:ctx_grid 10→16 保住细节。这是让任务对任何模型可解的必要条件。**

## 11. 【当前任务 · Phase 1】长丢失 + 拦截演示数据(核心贡献的数据前置,2026-08-17)

> 语言识别(H0)已证。数据侧转向**核心贡献:目标出可视范围后的预测-拦截重捕获**(VLA+WAM)。这是 §3 的**当前落地版**——**在 v5 已达标的几何/分辨率基础上继续**(保 512px + 几何三捷径全关 + 描述唯一 + `distractors/similar`,**不要回退**),叠加"长丢失 + 拦截"事件。目标数据版本:**mvp_full_v6**。

### 11.1 为什么(BC 的硬约束)
模型是行为克隆——**只能学专家演示过的行为**。要让模型学会"出画时飞向预测位置、重现处重捕获",**专家必须先在数据里就这么飞**。当前数据缺的正是这个演示。训练侧 `supervise_intercept`(mask 反转)代码已就位,**只等这批数据激活**。

### 11.2 必须造的事件(每集 ≥1-2 次)
1. **长丢失 5-15s+**,成因多样:(i) 拐弯出画;(ii) 建筑/大车**完全遮挡**;(iii) 与 look-alike **轨迹交叉**后紧邻;(iv) **出画后重入**。**目标必须重现**(不是丢了就结束 episode)。
2. **专家演示"拦截"而非"盲跟/放弃"**:专家(有目标 GT 特权)在丢失期间**飞向目标已知的未来 3D 位置**(抄近路直飞拦截),在重现处重捕获——**绝不结束 episode,也绝不无依据盲跟直行**。
3. **重现时 ≥2 look-alike 共视**:目标重现瞬间画面里有同描述-可分的 look-alike → 重捕获必须靠**语言**认领(而非"哪辆先出现就是它")。
4. **覆盖丢失时长谱**:短丢失(<6s,EAR horizon 内)+ 长丢失(>6s,需 WAM 世界建模)**都要有**,别只造一种。

### 11.3 标注(供训练 mask 反转 + E5 评测切片)
- **逐帧** `annotation/{occluded, off_screen}` 准确(标记丢失段);
- **`target/t{x,y,z}` 全程有效**(出画期间仿真器仍记录目标真值 3D → 这是"预测未来位置"的监督标签,已有,勿丢);
- 显式标记**重捕获帧**(重现后 N 帧)+ 该帧的 look-alike 共视(`distractors/similar` 逐帧可复算);
- **交叉/重现处不要让目标恒居某一相对位置**(否则又引入位置捷径,前功尽弃)。

### 11.4 验收
- **丢失时长分布**:中位/最长、≥5s 集数、>10s 集数(目标:显著多于 mvp_full 的 16.5s-max、覆盖 >6s 长丢失);
- **每个长丢失事件**都有:专家拦截轨迹(直飞预测位置)+ 目标重现 + 重现处 ≥2 look-alike 共视;
- **几何/分辨率不回退**:`benchmark_leak_probe` 仍接近 chance、512px、描述唯一;
- **训练侧联动**:数据到位后 `supervise_intercept` 激活,长丢失帧进入拦截监督(从"仅 mask"变"监督拦截动作")。

### 11.5 一句话
**在 v5 干净基础上,造"5-15s 长丢失 + 专家直飞拦截演示 + 目标重现 + 重现处 look-alike 共视"的事件,让模型有拦截行为可学、有重捕获可评。** 这是核心贡献(VLA+WAM 出画重捕获)的数据地基;闭环评测(E5/SR vs 丢失时长)见 experiment-design §7 + training-plan Phase P4。
