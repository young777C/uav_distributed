0总览:五阶段流水线

核心设计:冻结 VLM(Qwen3-VL-4B)对每帧只跑一次、缓存融合表征(③);可训练小模型(④,~150M)在缓存上迭代 → 多卡预计算、单卡训练。语言在③被融进图像 token(见 D2:有/无语言 token cosine 0.47)。

1数据处理:一帧视频 → 一个训练样本

每个样本 = 以第 i 帧为锚点。dataset_stage2.py。fps=10。

切分规则(_build_index)

  • 砍尾 60 帧(horizon=max_horizon6s×10)→ valid=n−60
  • 起点 i=0,3,6,…(stride 3),每集封顶 cap=500(覆盖全1500帧)
  • 相机系 waypoint:M=inverse_pose_matrix(cam); wp=(homog@M.T)/50 → 消 UAV 偏航歧义

★ 长丢失 / 预测-拦截处理

  • vis 判据=遮挡∧¬出画(否则长出画被误判可见→漏)
  • 目标缺席帧进样本:出画帧(无target候选)若6s内重现 → 保留,tid_valid=0、act_supervise=1(监督拦截动作)
  • EAR waypoint 用目标 GT(出画期间仍有效)→ 学"预测出画目标位置"
  • 门控 supervise_intercept=true;窗口 intercept_hz=6s

2冻结 VLM 预计算(Qwen3-VL-4B,`backbone_kv.py`)

每个 (RGB 336×336 + 语言指令) → 冻结 Qwen3-VL 前向一次 → 抽多层图像 token 存盘。

关键:缓存的 (5,100,2560) 是LLM 层的隐状态(2560维),不是 ViT 裸特征(1024维)——即"图像经 ViT→connector→与语言在 LLM 融合"后的联合表征。100=空间 token 数,2560=每 token 维度,5=抽取层数。cap=500 → 每集缓存 500 帧。

3模型架构:四个可训练模块(冻结VLM下游)

输入=缓存 token + proprio + 候选;输出=动作块 + 目标选择。三重 cross-attention 融合。

模块做什么关键维度(config_full)
EAR 显式动作推理flow-matching 生成 K=4 个相机系 3D waypoint(1/2/4/6s)=预测目标未来位置/拦截点;条件=vlm_ctx+propriod_model 256, 4层, 4头, proprio 5
IAR 隐式动作推理对 5 层缓存逐层 KV 查询,提取"即将遮挡/机动/混淆"等说不出的先验 → z_imd 256, n_im 8, 4头
DiT 动作头flow-matching 生成 16 步动作块;三重 cross-attn:Q_action↔z_ex(EAR waypoint)/z_im(IAR)/vlm_ctx,并入 propriod 512, 32层, 8头, d_ex 3, d_im 256
target-id 消歧头Linear(cand)⊙Linear(mean(ctx)) → GELU → 打分,候选间 softmax 选目标d 256 · ⚠️ mean 池化稀释语言(待改 cross-attn)

4训练流程:Stage-1 EAR 预热 → Stage-2 联合

Stage-1:EAR 预热

  • 仅训 EAR,冻结其余;监督=相机系 waypoint GT
  • flow-matching:学"噪声→waypoint"的向量场
  • 产物 stage1_ear_best.pt → Stage-2 warmstart

Stage-2:端到端联合

  • EAR(warmstart)+IAR+DiT+target-id 一起训
  • 课程 a→c:WeightedRandomSampler 每 epoch 重加权(a_floor 0.25, ramp 0.9)
  • staleness 增强(p 0.3):随机复用过期 z_ex,匹配 S1/S2 异步
  • grad_clip 1.0;50 epoch;单卡
L = L_action + 0.3·L_ear + 0.1·L_visibility + 0.1·L_maneuver + 0.2·L_target-id
损失定义mask
L_action(主)DiT 动作块 flow-matching MSE(向量场)× act_supervise(可见∪拦截帧才监督)
L_ear (0.3)EAR waypoint flow-matching MSE全帧(waypoint GT 恒有效)
L_visibility (0.1)IAR occ_structural 头 MSE—
L_maneuver (0.1)IAR 机动头 BCE—
L_target-id (0.2)候选 cross-entropy(选对目标车)× tid_valid(目标缺席帧不算)
当前诊断(全量): mis_follow 卡在位置 floor 41.6%(ep49=42.4%),act_mse 收敛但消歧没解决 → target-id 头把语言均值稀释了(D2 证明语言在缓存里)。修复:target-id 头改 候选→上下文 cross-attn + 提 loss 权重 + 数据侧去深度捷径(见 language-grounding-plan.md)。

5推理流程:双系统闭环 + 预测-拦截

flow-matching:训练 vs 推理

  • 训练:学向量场 v(a_t,t)=a1−z(算 loss)
  • 推理:从噪声出发,8 步 Euler 积分 ODE 采样出动作/waypoint

★ 出画预测-拦截重捕获

  • 短丢失(<6s):S2 最后可见帧的 EAR waypoint 经 staleness 复用为拦截点 → 直飞
  • 长丢失(>6s):超 EAR horizon → 需目标状态记忆(VLA→WAM 架构方向)/ search+语言重捕获
  • 重现时若有 look-alike → 只语言能定"哪辆" ← 核心贡献
