## 1. 创新点升级方向(本轮要验证的核心假设)

**从"给单个记忆加一个门控包装器"升级为:"闭环身份 = 对多个异构自更新记忆 + 语言规格的、按误差相关性回火的证据融合,并把融合后验反馈门控每个记忆的更新"。**

- **C1(问题化,沿用)**:闭环指代重捕获中的身份失效 = 自更新记忆的确认偏差;对 SAM2 类强记忆同样成立(P4 是新的直接证据)。
- **C2(方法,升级)**:PGIF 从"包 TAHRelM"推广为**异构记忆融合层**——每个记忆(TAHRelM、DAM4SAM、语言 grounding)给出"选择 + 置信度",按各自的置信度秩加权、按误差相关时间回火,融合成一个 tracklet 级后验;后验再门控**每个**记忆的更新/重置。
- **C3(方法,新增)**:**延迟承诺的冷启动**——开局先在 tracklet 上积累语言(+ 记忆)证据,证据充分才承诺,攻 P3。
- **C4(理论,沿用并扩展)**:命题 2 扩展到多源:各源误差相关性不同 → 各自回火;源之间误差近似独立时融合才有增益(可检验)。

各版本对应的可检验预测见 §3。

## 2. 版本路线(每版先过 codex 创新点审核,再做闭环)

| 版本 | 内容 | 攻哪个问题 | 预注册假设(Town05,n=19 配对) | 主要改动 |
|---|---|---|---|---|
| **V0** | 冻结当前基线(TAHRelM + PGIF;所有臂 deployable 结果已有) | — | — | 无 |
| **V1** | **PGIF ∘ DAM4SAM**:把 PGIF 包在 DAM4SAM 外层;重置钩子 = 用 ŝ 的框重新 `init` SAM2 | P1、P4,并检验 C2 的跨记忆泛化 | 正确比例不低于 DAM4SAM(非劣,Δ 下界 > −0.05),最长锁错显著低于 DAM4SAM | `dam4sam_service.py` 返回 SAM2 预测 IoU 作置信度;`policy.py` 加 dam4sam 的 PGIF 门控(重新 init) |
| **V2** | **延迟承诺冷启动**:前 k 个决策步只积累语言证据(回火)、不承诺;可选:把阶段 0 的 LoRA r16 grounding 头作为语言打分器 | P3、P2 | 冷启动锁错比例下降;最长锁错均值显著下降 | `asd.py` 增加冷启动窗口;`policy.py` 冷启动路径 |
| **V3** | **异构证据融合**:TAHRelM + DAM4SAM + 语言 三路观测进入同一个回火后验,门控两个记忆 | P1、P2、C2/C4 | 正确比例显著高于 DAM4SAM,最长锁错显著低于 DAM4SAM 与 PGIF(V0) | 两个记忆同时运行(DAM4SAM 服务 + TAHRelM),`asd.py` 多观测融合 |
| **V4**(时间允许) | **重捕获感知回火**:目标 tracklet 重新入画后短窗口内提高新证据权重 | P5 | 重捕获率不低于无纠偏,正确比例不下降 | `asd.py` |

**去留规则**:某版本闭环未达到预注册假设 → 如实记为负结果(写进 roadmap),不进入下一版的组合;达到 → 作为下一版的基座。

## 3. 每个版本的流水线(固定步骤与门控)

```
(a) 设计文档 v_k(≤30 min)
      → codex 审核 R_k^a:只审创新点与逻辑(是否足够 SCI 一区 / CCF-A;与 DAM4SAM、MHT、自训练确认偏差、TLD 等的区别)
        判据:无 MAJOR → 进入 (b);有 MAJOR → 修改设计后重审,最多 2 轮;仍有 MAJOR → 该版降级或放弃
(b) 实现 + 单测 + 1 episode 冒烟(≤45 min)
(c) 闭环主实验:Town05,seeds 91000–19,deployable,3 台 CARLA 并行(约 80–90 min/臂)
(d) 门控 G_k:按 §2 预注册假设判定(配对 bootstrap 95% CI,三项指标)
(e) 泛化实验(仅通过 G_k 的版本):Town10HD + Town03(训练集外地图)各 20 ep,与 DAM4SAM、V0 配对
(f) codex 审核 R_k^b:审"证据是否支撑创新点"(过度声称、统计、公平性)
(g) 写入 1003_iteration_roadmap.md:假设 / 设计 / 数据路径 / 两轮 codex 结论 / 去留
```

**审稿 prompt 模板**(`runs/asd/codex_review.sh <out.md> "<prompt>"`,stdin 已关闭):
- R^a:"你是 [T-RO/RA-L 审稿人 + CCF-A AC]。审 `acot_note/1003_v{k}_design.md`:创新点是否足够、与相关工作的差异是否成立、逻辑是否闭合、预注册假设是否可证伪。输出 verdict(NO MAJOR / MAJOR)+ MAJOR/MINOR 与修改建议。"
- R^b:"审 `1003_v{k}_evidence.md` 与数据 `eval_out/...json`:证据是否支撑主张、有无过度声称、统计与公平性问题。"

## 5. 统一规范(所有版本必须遵守)

1. **只用 deployable**:身份决策不使用真值(候选框与车辆定位为仿真理想输入,写作中声明)。gt-seeded 不进入任何对比。
2. **三项客观指标**:正确锁定比例、最长连续正确锁定、最长锁错(scorer 逐帧字段);SR 只放附录。
3. **同种子配对**:主实验 seeds 91000–19;扩种子 91020–39;配对 bootstrap 95% CI;冷启动分层用 `rollout/tick_align.py` 对齐。
4. **预注册**:每版的超参数在跑闭环前写入设计文档并冻结,不在评测种子上调参。
5. **诚实记录**:未达预期的版本作为负结果写入 roadmap,并给出机理解释。
6. **基础设施**:每个臂独立 TM 端口;CARLA 与 policy 不共用 GPU;后台任务关闭 stdin;运行日志写入 `runs/asd/iter/`。

## 6. 主要风险与预案

| 风险 | 预案 |
|---|---|
| Town03 场景生成失败(场景配置/遮挡缓存) | 预检时 2 ep 冒烟;失败则泛化只用 Town10HD + 跨记忆,并在 roadmap 中说明 |
| DAM4SAM 重新 init 开销大、闭环变慢 | 限制重置频率(冷却 r 步);记录每 ep 耗时 |
| V3 两个记忆同时运行显存/时间翻倍 | DAM4SAM 服务单独占 GPU 6;必要时 V3 只跑 Town05 + Town03 |
| 只有 3 台 CARLA 健康,槽位不足 | 优先级:V1 > V2 > V3 主实验 > 泛化 > 扩种子 > V4 |
| codex 连续两轮 MAJOR | 该版本降级为消融或放弃,roadmap 记录原因 |

## 7. 成功判据(12h 结束时)

- **性能**:存在一个版本在 Town05 上正确锁定比例 **不低于** DAM4SAM(非劣)且最长锁错 **显著低于** DAM4SAM;最好同时在 Town03(训练集外)上方向一致。
- **创新点**:最终版本的设计与证据各通过一轮 codex 审核且无 MAJOR。
- **文档**:`1003_iteration_roadmap.md` 完整记录每个版本(含负结果)。
