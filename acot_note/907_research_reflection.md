## 一、研究弧线(一段话)
从"空中·语言指定·多相似车消歧跟踪"的 VLA 出发 → 发现**语言在纯跟踪上几乎无净贡献**、任务需升级为**长丢失预测-重捕获** → 建 WM 前用 oracle 诊断,**重构瓶颈:SR 墙是 WHICH(身份重捕获)不是 WHERE(预测)** → 沿 WHICH 做**外观/时序 re-ID 阶梯**(crop-DINOv2+gallery+时序EMA)→ 证伪控制侧修取景(BC/RL 居中)→ 借鉴外部方法(运动共识 borrow#1 使 SR 翻倍)→ 试图把"大乱炖"启发式栈**蒸馏成一个可学模块(TAH)**,遇 offline→online gap,正用 DAgger 修。

## 二、遇到的核心问题 + 解决思路(每条:问题 → 思路 → 教训)

**1. 指标造假 / 捷径:结论可能是假的**
- 问题:早期"语言有效"是 argmax tie-break × target-always-idx0 的**指标伪影**;还有"最居中即目标"的**位置捷径**。
- 思路:先**净化指标**(shuffle 候选、permutation-equivariant 检查)、**去相关数据**(逐个关几何捷径)、**探针量化捷径**(benchmark_leak_probe)。
- 教训:**任何结论先问"是不是指标/捷径造的假?"**——净化指标优先于一切。

**2. 追错瓶颈:WHERE vs WHICH**
- 问题:一度以为瓶颈是"预测出画位置(WHERE)",投入 WM/road-graph。
- 思路:**建 WM 前先用 oracle 诊断**——road_oracle(近完美 WHERE)SR 仍 0;D1(专家取景)/D2(oracle 身份)各自到 0.58 → 瓶颈是 **WHICH + identity×control 级联**。
- 教训:**动手建复杂模块前,用 oracle/上界探针定位真瓶颈**,别凭直觉投入。

**3. ★offline↔online gap(贯穿全程的头号敌人)**
- 问题:**离线指标漂亮、闭环崩**——反复出现:BC-居中离线 corr 0.97→闭环崩;reid 离线↔在线有 gap;RL-E0 R_center 0.98→闭环失效;**TAH 离线 val 0.909→闭环 correct 0.681**。
- 思路:**闭环/on-policy 才是唯一真检验**;根因常是**分布漂移**(训练在专家取景、部署是 off-center 取景);修法 = **DAgger/on-policy 训练**(正在做)。
- 教训:**永远不信离线数,闭环定生死**;offline→online 是这类具身任务的结构性难点,须从一开始就规划 on-policy 验证/训练。

**4. 指标本身钝化:latch-SR 饱和**
- 问题:SR 是 latch(90s 内一次≥2s 错窗→永久失败,SR≈(1−q)^N),**饱和近 0、对方法差异无分辨力**——temporal reID 身份更好却 SR→0;RMOT=0.7 连续指标最优却 SR 最差。
- 思路:改报**客观连续指标**(正确跟踪占比/最长错跟时长/重捕获率/latch@Ts),SR 降为一个保守操作点。
- 教训:**指标设计本身是研究对象**;当主指标不能分辨方法时,先修指标而非硬堆方法。

**5. kitchen-sink 大乱炖**
- 问题:追 SR 一路补启发式(gallery/EMA/运动共识/共识门/conf-tau),变成**工程建模而非算法研究**;实测 **borrow#2 共识门边际转负**(SR 0.263→0.053)。
- 思路:**停止加法**,把启发式栈**提炼成一个可学模块(TAH,4610 参)**。
- 教训:**"再加一个组件就更好"是危险惯性**;边际转负是停止信号;该从"加法"转"提炼"。

**6. 学习 vs 启发式:要学"对"的东西**
- 问题:**学习控制(BC/RL 居中)全失败**,免训练启发式反而 work;但 **TAH 学习又栽 offline→online**。
- 思路:学习要学**可学且信号在**的东西——**身份关联可学**(DINOv2 已证 look-alike 可分),**控制/居中在身份下游、耦合身份错、不可单独学**;且学习模块要**车辆不变(相对特征)**才泛化 + **在部署分布上训**(DAgger)。
- 教训:**"能不能学"取决于信号在不在 + 学的是不是下游耦合量 + 分布对不对**,不是"上个网络就行"。

**7. 过拟合 / 泛化(小数据 + 开集身份)**
- 问题:TAH v1(绝对嵌入 72.5万参)在 64 episodes 上过拟合(train 0.76≫val 0.52)。
- 思路:**相对/车辆不变特征**(cos-to-memory⊕相对运动,学门控不学编码器,4610 参)+ **增广**(置换/特征噪声/位置抖动)→ 过拟合 gap 0.244→0、val 0.52→0.91。
- 教训:**开集泛化靠"把可学函数收成域不变的小函数"** + 增广,而非更大模型;把不变的部分(外观比对)交给冻结骨干。

## 三、方法论收获(更深一层)

1. **oracle/启发式 = 诊断探针 + baseline,不是要交付的系统**。它们回答"信号在不在、天花板多高、杠杆是啥";真正的方法应体现由此得到的洞见。
2. **闭环/on-policy 是唯一真检验**;离线指标会骗人,尤其分布漂移大的具身任务。
3. **诚实纪律(反复救我)**:永远同种子配对;正控制先于信 delta;不美化(外部 baseline 胜我们的指标如实报);**点破对自己有利的假象**(RL 的 latch@5s=1.0 是近零跟踪、DAM4SAM 的 0.94 正确率却 SR 0.105);单点强结果必邻域扫描确认非幸运数(RMOT sweep)。
4. **负结果是贡献**:WHERE/WM 无用、BC/RL 居中失败、reanchor 语言证伪、borrow#2 反害——**带机理的负结果**既定位了杠杆、又保护论文(审稿人问"为什么不试 X"→我们试了、报了)。
5. **从假设/洞见出发,不从数字出发**:我们的乱是"追 SR 的工程惯性"产物;成熟做法是假设先行、方法体现洞见。
6. **该停就停**:边际转负(borrow#2)、指标饱和(latch-SR)、加法变乱炖——都是"转向"的信号。

## 四、成熟研究者会怎么做(自省)
- **假设先行**:"look-alike 重捕获 = 时序关联问题" → 一开始就设计干净可学关联模块,而非末尾蒸馏;
- **启发式当探针/baseline**,不当系统;
- **方法体现洞见**(TAHRel 的卖点是"相对/车辆不变可学关联",不是"压缩了 5 个启发式");把它 frame 成 **learnable data association / 算法展开**(LISTA/GNN-MOT 谱系),从"工程蒸馏"升为"有根的算法贡献";
- **论文呈现干净逻辑**(假设→探针→方法→消融),**过程的乱不进论文**。

## 五、本研究的净收获(可写进论文的硬内容)
1. **任务/benchmark**:空中·语言·look-alike 消歧·闭环·长丢失重捕获(四轴交集)。
2. **诊断发现**:SR 墙是 **WHICH-under-reacquisition** 非 WHERE;**单帧语言 grounding 是天花板**;瓶颈是 **identity×control 级联**;~42% 场景地板。
3. **杠杆**:**外观/时序 + 运动共识的 re-识别**(reid-DINOv2+gallery+时序EMA+运动共识 borrow#1,SR 0.105→0.263,外部方法独立证实方向)。
4. **方法学**:客观连续指标(反 latch-SR 钝化);去相关+分辨率的因果语言检验。
5. **诚实边界**:offline→online gap 是核心难点;学习模块须车辆不变 + 部署分布训练(DAgger);我们非 SOTA,贡献是**诊断+发现+方法学+一个诊断驱动的可学关联模块**。

## 七、控制论视角:offline→online 的第二读法(2026-09-08,零成本 framing)

> 动机:offline→online gap 有三种读法——**分布**(covariate shift→DAgger)、**控制论**(反馈回路稳定性)、**表征**(域不变性)。我们一直只用第一种。本节零成本(复用现有闭环日志,0 次新 rollout)补上**控制论读法**。工具 `carla_uav_tracking/rollout/control_stability.py` → `eval_out/stability_control.json`;图 `figs/stability_plane.html`(→`.png`)。

**核心洞见:gap 不只是"没见过的状态",它是一个有最优阻尼的正反馈回路。**"坏帧→误认→飞错车→更坏帧"是身份→控制的**正反馈**;我们一直报的指标其实是**闭环稳定性观测量**:
- `max_wrong_run_s` = **整定时间**(误差持续/回路多久回不到正轨)
- `q_reacq` = **恢复率**(每次丢锁的返回概率)
- `id_switches` = **振荡/极限环**(在 look-alike 间抖动)
- `track_correct_frac` = **稳态跟踪**

**稳定性表(n=19 同种子,按阻尼主轴排序)**:

| 臂 | 控制角色 | 稳态↑ | 恢复q↑ | 持续(mean s)↓ | 振荡↓ | SR |
|---|---|---|---|---|---|---|
| xattn | 欠阻尼 | 0.251 | 0.448 | 9.44 | 13.7 | 0.000 |
| reid | 无门 | 0.653 | 0.651 | 4.20 | 15.4 | 0.105 |
| +conf门 | 阻尼 | 0.671 | 0.607 | 3.78 | 14.1 | 0.105 |
| +EMA | 滤波 | 0.738 | 0.471 | 3.18 | 9.3 | 0.105 |
| **borrow#1** | **甜点阻尼** | 0.810 | **0.635** | 3.07 | 7.7 | **0.263** |
| borrow#1@.7 | 过约束 | 0.853 | 0.549 | 2.48 | 6.7 | 0.105 |
| borrow#2 | **过阻尼→崩** | 0.813 | 0.604 | 3.54 | 6.6 | 0.053 |
| TAH | 学习·离线 | 0.681 | 0.490 | 4.22 | 10.4 | 0.053 |
| **TAH+DAgger** | 学习·on-policy | 0.716 | 0.438 | 3.11 | 8.3 | 0.158 |

**读数(数据自证的三个论断)**:
1. **加阻尼单调改善,直到甜点**:欠阻尼 xattn(持续 9.4s、振荡 13.7、稳态 0.25)→ 逐步加门/共识 → borrow#1(持续 3.07、SR 峰值 0.263)。阻尼把点推向左上"好角"。
2. **存在最优阻尼——过则害**:borrow#1@.7(运动门过紧)、borrow#2(共识门)两次独立翻车。签名是**稳态还在升、SR 已崩、恢复率下掉**——过阻尼锁得太死,真需重捕获时**恢复不了**。这**一句话解释了 borrow#1 有效 vs borrow#2 反害**的老谜题(此前只当"边际转负"经验现象)。
3. **DAgger 的控制论定位**:沿橙箭把 TAH 从 (4.22, 0.49) **左移**到 (3.11, 0.44)——**压住了尾部灾难性发散**(latch@5s 0.68→0.95、mean 持续 4.22→3.11、SR 0.053→0.158,3×)**但没提升恢复率**(q 0.49→0.44),落在 borrow#1 好角**下方**。

## 八、B 路线终判 + 三视角的实证分工(B1 DAgger,2026-09-08)

**B1 结果**:DAgger 显著改善学习模块(SR 3×、灾难性长错窗基本消除),**但仍输启发式栈**(tahdag track_correct 0.716 < l5 0.738 < borrow#1 0.810;SR 0.158 < 0.263;q_reacq 0.438 全场最低)。**按预注册判据(907_model-integration-907 §6)→ B 不达标,退回 A**:borrow#1 运动共识作正文唯一有效升级,TAHRel 降为**带机理的负结果/消融**(证明"相对特征学习模块信号在、但 on-policy 也追不平手工栈")。

**但这不是平淡失败——它把三视角的分工实证了**:
- **分布视角(DAgger)**:✅ 部分成立——补上部署分布数据确实带来 3× SR、尾部阻尼。**gap 有一大块是分布性的**。
- **残余 gap ≠ 分布**:DAgger 补完分布后,tahdag 仍在好角下方,差在**恢复率**(q 0.44 vs borrow#1 0.635)。→ 残余属**控制(恢复动力学)**——手工 borrow#1 的运动共识显式提供了"重捕获时往哪找"的先验,学习模块没学到;以及可能的**表征不变性**(对部署 off-center 取景的特征不变性)。
- **结论**:三视角非竞争而是**互补的分层**——DAgger 补分布(已做,见效但不够);要过 borrow#1 的杠,需补**恢复动力学(控制)** 或 **取景不变性(表征)**,不是更多 DAgger 数据。**这实证支持了"增加研究视角"的判断,并给出了下一杠杆的方向。**

## 九、三视角闭合:控制视角 → 可学运动门 → B 路线胜出(A1,2026-09-08)

三视角(分布/控制/表征)不是并列口号,而是**逐步定位并闭合 gap 的路线图**,A1 把它走完:
1. **分布(DAgger,B1)**:补部署分布 → SR 0.053→0.158、尾部阻尼。但残余 gap 仍在。
2. **控制(可学运动门,A1)**:B1 用稳定性平面**定位残余=恢复率 q_reacq**(borrow#1 靠显式运动先验赢的那一项)。A1 把该先验编码为**可学软运动门 `exp(−‖relp‖/gate)`+EMA 速度**(TAHRelM,4740 参,OFAT)→ **q_reacq 0.438→0.590、SR 0.158→0.316(全场第 1)、max_wrong 3.1→1.90(全场最短)、latch@5s→1.000**。
3. **表征(取景不变)**:off-center track_correct 0.818(全场最优)+ central↔off gap 0.027(全场最小)佐证 DAgger 已补取景不变性,无需额外机器。

**★最关键的验证:offline→online gap 这次没栽**——TAHRelM 离线 0.990 **transfer 到闭环**(对比 TAHRel 0.909→0.681 崩)。根因:运动共识是**相对几何信号**(候选 vs CV 预测位),**天然抗部署取景漂移**;而 TAHRel 输给 gap 是因它更依赖会漂移的外观加权。→ **贯穿全项目的头号敌人(offline→online)在"用相对/不变信号 + on-policy 数据"下被制服**,这是比某个 SR 数更硬的方法学收获。

**B 路线阶段结论(oracle-memory 关联质量)**:gt-seeded 下,一个 4740 参可学模块在 SR、error-persistence、latch 全谱、密度、off-center 均全场最优。**从"kitchen sink 工程"到"诊断驱动的可学模块"**:①oracle/稳定性探针定位真瓶颈;②把手工启发式蒸馏为**车辆不变的可学相对特征**;③相对信号制服 offline→online 的**训练分布**部分。

**★★但 deployable 复评揭示更深一层(committed-seed,2026-09-11)——诚实修正**:去掉 oracle 记忆(gt-seeded=记忆每帧用 GT crop),改 committed(记忆从认定目标更新)后 **TAHRelM 崩**:SR 0.316→**0**、track_correct 0.746→**0.146**、max_wrong 1.90→**18.66s**,且**< deployable reid 0.363**。→ **gt-seeded 数是"给定理想记忆的关联质量上界",不是 deployable SR**。**这是"offline→online"的第三层**:不止训练分布(DAgger 已补)、不止恢复动力学(运动门已补),还有 **memory-seeding 层**——deployable 冷启动无语言引导(锁 candidate 0)+ 自监督记忆自我强化错锁。**教训再次坐实"闭环/deployable 定生死"**:oracle-memory 的漂亮数会掩盖 memory-init/drift 的致命缺口。**修正此前"B 全面胜出 deployable"的过度声称**;deployable 需 committed + 语言冷启动 + reanchor(进行中)。

## 十、一句话
**这项研究最大的收获不是某个模型,而是一套"如何诚实地定位并验证一个具身任务的真瓶颈"的方法**:用 oracle 探针定位杠杆、用闭环/on-policy 证伪离线幻觉、用客观指标穿透饱和判据、用负结果排除歧路、并在"加法变乱炖"时及时转向"提炼一个体现洞见的可学模块"。
