# 1003 · V3 设计文档:异构记忆 + 语言的回火证据融合(预注册;闭环前冻结)

> 2026-10-02 · 属于 `1003_iteration_workflow.md` 的 V3,是本轮迭代的**核心方法贡献**。所有实验 deployable(身份决策不用真值;候选框与车辆定位为仿真理想输入),CARLA 在线闭环,三项客观指标,配对 bootstrap 95% CI。V1/V2 的设计与审核见 `1003_v1_v2_design.md`、`codex/1003_R1a_R2a*.md`。

## 1. 动机(数据)
- 两类自更新记忆的失效形态**互补**:TAHRelM + PGIF(V0)长连续正确锁定强(21.3 s)但正确比例低(0.583);DAM4SAM 正确比例高(0.786)但粘滞错锁最长(26.7 s,中位 21.6 s)。
- 命题 2(`1001` §4):回火证据累积的价值取决于观测误差的相关时间。若两类记忆的错误**彼此相关性低**(一个锁错时另一个往往仍对),把它们作为两路独立观测融合,可在不增加单个记忆能力的前提下降低身份错误;若高度相关,融合无增益——这是一个**可证伪**的预测。

## 2. 方法
每个决策步,三路观测(各自只给"选择 + 任意尺度置信度"):
| 源 m | 选择 s^m | 置信度 c^m |
|---|---|---|
| TAHRelM | argmax 关联分数 | logits top1−top2 |
| DAM4SAM | 离 SAM2 预测框中心最近的候选(160 px 门限内;无匹配则本步缺席) | SAM2 预测 IoU |
| 语言 grounding(冻结 Stage-2 头) | argmax 语言 logits | logits top1−top2 |

- **逐源尺度无关权重**:w^m = 0.5 + rank(c^m; 该源最近 30 步)。
- **回火融合证据**(tracklet 级):L_k ← λ·L_k + Σ_m α_m · w^m · 1[k = s^m],λ = 0.98(与 V0 相同)。
  源权重 α 预注册为 α_TAH = α_DAM = 1,α_lang = 0.5(语言单帧准确率约 0.42,低于两类记忆;取半权,未在评测种子上调)。
- **后验门控两个记忆**:ŝ = argmax_{可见 k} L_k;
  - 若 ŝ ≠ s^TAH:TAHRelM 本步改用 ŝ 的截图重做更新(与 V0 相同);
  - 若 ŝ ≠ s^DAM:用 ŝ 的框重新 init SAM2(冷却 3 步,与 V1 相同);
  - 控制承诺 ŝ。
- **冷启动**:若 V2 通过门控 G2 → V3 继承 V2 的延迟承诺组件(K=5,λ_lang=0.9,先验截断 3);否则不加(预注册的条件分支,结果出来前确定)。

## 3. 预注册假设(Town05,seeds 91000–19,n=19 配对)
- **H3a(主)**:V3 正确锁定比例**不低于 DAM4SAM**(Δ 的 95% CI 下界 > −0.05)**且**最长锁错显著低于 DAM4SAM(CI 上界 < 0);
- **H3b**:V3 相对 V0(TAHRelM+PGIF)正确锁定比例显著更高(CI 下界 > 0);
- **H3c(机理,可证伪)**:在 V3 的 tick 日志中,TAHRelM 与 DAM4SAM 的"选错"指示之间的相关系数 ρ_err 报告并检验:预测 ρ_err < 0.5;若 ρ_err 高(≥ 0.7)而 V3 仍有增益,则增益不能归因于"误差独立的融合",须另找解释。
- **消融(预注册,时间允许按顺序跑)**:V3-noDAMgate(不重置 SAM2,只融合)、V3-nolang(α_lang = 0)。

## 4. 与相关工作的差异
- **多跟踪器融合 / 集成跟踪**(如基于投票或置信度的 tracker ensemble):通常在单帧或短窗做加权选择,**不把融合结果反馈去门控各成员的记忆更新**;V3 的融合后验同时决定"承诺谁"和"每个记忆该从谁学",直接针对各成员的确认偏差。
- **MHT / 身份管理**:维护多目标身份假设;V3 只维护单一指代身份的证据,观测来自异构的学习/非学习记忆与语言。
- **DAM4SAM 的 DRM**:改进的是 SAM2 内部的写入策略;V3 在记忆外部、跨记忆地做纠错与重置。
- **自训练确认偏差**:离线伪标签平滑;V3 是闭环在线、跨多个自更新记忆的版本,并给出"误差相关性决定融合增益"的可检验预测(H3c)。

## 5. 实现
- `rollout/policy.py`:新 `tid_head = "fusion"`:同一 tick 运行 TAHRelM(含记忆)与 DAM4SAM 客户端;语言 logits 来自现有 grounding 头。
- `rollout/asd.py`:`step_multi(aidx, [(slot, conf, source), ...])`——逐源维护置信度窗口,按 §2 融合;返回 ŝ 与每个源是否需要门控。
- 日志:每 tick 记录三路选择、置信度、ŝ 与真值(仅离线打分),用于 H3c。

## R3a 审核后的修订(第二轮预注册;意见见 `codex/1003_R3a.md`)

1. **源权重去启发式**:主设定改为**三路等权**(α_TAH = α_DAM = α_lang = 1),不做任何选择;报告各源对"选中真目标"的 AUROC、缺席率(DAM 无匹配、语言无候选)。α 敏感性列为后续(不在评测种子上调)。
2. **机理检验去闭环污染(H3c 改为解释性)**:新增 **V3-ensemble** 臂——同一 policy 同时运行两个记忆与语言,控制承诺 = 每步三路**等权单帧投票**(不回火、不回灌门控,两个记忆各自按自身选择自更新)。该臂既是"普通异构集成、无记忆反馈"的对照,也是测量**门控前**误差相关的干净来源:在其日志中报告 ρ_err(TAH 错 vs DAM 错的相关)、P(DAM 错 | TAH 错)、错锁区间重叠率。V3 内部的相关性只放附录。
3. **门控拆分对照(预注册)**:
   - **V3-commit-only**:回火融合只决定承诺,两个记忆都不门控 → 检验"把后验回灌给记忆"是否必要;
   - **V3-gateTAH-only**:只门控 TAHRelM,不重置 SAM2 → 检验"只门控一个记忆"与"群体确认偏差"(条目 4);
   - 判定:V3 显著优于 V3-ensemble(主)与 V3-commit-only,才能主张"融合后验回灌门控"是增益来源。
4. **群体确认偏差监测**:日志记录门控前后两源分歧率、错误门控次数(把正确的源改到错误身份)、SAM2 重置次数;报告错误门控占比。
5. **V2 分支不再按评测结果选择**:V3 主表**同时报告** V3(无冷启动组件)与 V3+V2(K=5,λ=0.9,先验截断 3),两者都预注册。
6. 收窄表述:V3 是单一指代身份的后验累积,不声称解决多目标身份管理;H3a 同时报告最长连续正确锁定;DAM4SAM 门限 160 px、冷却 3 步沿用 V1,报告缺席比例/重置次数/耗时。
