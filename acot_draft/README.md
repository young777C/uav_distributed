## PDF build & auto-update
The machine has no system LaTeX, so the draft ships with **Tectonic**
(a single self-contained binary in `.tools/`, no root needed). It resolves
citations automatically (bundled BibTeX) and fetches packages/fonts on first
run (cached under `~/.cache/Tectonic`).

```bash
./build.sh        # or: make        -> compile main.tex to main.pdf once (~6 s)
./watch.sh        # or: make watch  -> AUTO-UPDATE: rebuild main.pdf on every save
make clean        # remove build intermediates (keeps main.pdf)
```

`watch.sh` polls `main.tex`, `references.bib`, and `figures/` once per second
and recompiles `main.pdf` whenever any of them changes (no inotify/entr
needed, works over NFS). Leave it running in a terminal while you edit;
the PDF stays current. On a build error it keeps running and prints
`BUILD FAILED` — run `./build.sh` to see the LaTeX error, or read `main.log`.

If `.tools/tectonic` is ever missing, re-download it:
```bash
mkdir -p .tools && curl -sL \
 "https://github.com/tectonic-typesetting/tectonic/releases/download/tectonic%400.15.0/tectonic-0.15.0-x86_64-unknown-linux-musl.tar.gz" \
 | tar xz -C .tools && chmod +x .tools/tectonic
```

## One-sentence argument
In language-conditioned aerial vehicle tracking, an action-space
chain-of-thought VLA flies a UAV to follow a natural-language–specified
target car among visually similar distractors; the contribution is the
task/benchmark intersection and its load-bearing-language design, with the
EAR/IAR/AGP mechanism transferred (not invented) from ACoT-VLA, evaluated
sim-only.
